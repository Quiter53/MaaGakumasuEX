# 更新公告

# v2.1.2

## 新增 | New

- 规则模式下，「国民的アイドル」新增「选择要生效的牌」，可指定一张配合牌并随时清除，普通与强化版本共用设置。
- SSR 卡牌新增降至 R／SR 出牌档位的选项，仅影响战斗出牌排序；获取、购买、删换牌与回忆判定沿用原稀有度。
- 初星黑醋新增「跟随规则模式判断」：准备打国民或配合牌时，另一张不在手中才使用并取回；两张都在手中或没有黑醋时按原规则出牌。取牌后重新按优先级排序，国民成功打出后的下一张牌跳过黑醋检查。

## 改进 | Improved

- 规则设置页增加国民与配合牌的回合及排序冲突提示；黑醋移动页优先选指定牌，找不到时改选可识别候选中规则优先级最高的牌。
- 商店体力与 P 点数改为固定数字区域的单行识别，排除爱心与 P 图标；点数兼容裸四位数、规范千位逗号及全角数字。
- HIF 商店自定义改为建立待办后逐张执行，完成全部已确认目标后直接处理饮料；保留待办跨刷新继续，先处理当前饮料再按预算刷新。

## 修复 | Fix

- 修复脚光等卡牌自定义完成后，无条件重新进入列表扫描并提示「选中卡名称未确认」的问题；跳过明确标记「已自定义」的不可选卡牌。
- 修复自定义菜单中读取遮罩下余额的问题，菜单内核对卡名、选项和次数，返回清晰商店后再核对实际扣款；兼容成功后直接返回商店的流程。
- 修复商店体力与爱心一同识别导致置信度不足、跳过回血检查的问题，保留原体力识别门槛与回血预算规则。
- 修复战斗体力图标单帧漏识别时立即退出出牌、重建饮料及组合状态的问题，补充有界复核，恢复后使用新截图继续同一场战斗。
- 修复卡组回忆中 Stage 页签点击未生效仍继续读取、页面变化后沿用旧截图的问题；确认无 Stage 卡组时仍按设置使用再生成票，不提前放弃。
- 修复卡组回忆中，非目标卡或额外同名卡的未知识别结果误阻止已经满足目标的卡组通过的问题，重复目标仍要求独立合格副本。
- 修复回忆保存后停留在奖励结算页面的问题，核对粉丝数、获得道具、培育记录与下一步按钮后交回原结算流程。
- 修复任务日志中的旧颜色标记被误当作图片路径、产生无效路径警告的问题。

## 文档 | Docs

- 新增识别置信度调整指南，列出各模块的修改入口、阈值方向、运行时覆盖关系、示例及验证方法。
- 补充国民与初星黑醋策略、卡组回忆目标条件，以及商店识别和自定义流程的排查记录。
