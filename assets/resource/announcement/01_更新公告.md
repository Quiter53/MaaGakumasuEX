# 更新公告

# v2.2.0

## 新增 | New

- 客户端界面整体改为液态玻璃风格，全部使用原生控件实现，提供深浅两套主题；默认蓝色主题使用新的强调色，原有颜色主题设置继续生效。
- 任务工作台改为可自由排布的面板：拖动面板标题即可上下叠放或左右分列，拖动过程中实时让位并预览尺寸；分隔条可调整列宽和面板高度，支持最大化与还原、恢复默认布局和键盘移动。布局自动保存，首次启动时迁移旧版布局；实时画面默认关闭，可在工具栏开启。
- 出牌规则页新增“新建预设”“管理预设”、规则搜索、曲线模板、折线/阶梯两种模式、节点精确编辑，以及可选的“总回合数”；手牌模拟的回合范围跟随总回合数，可移除手牌，回合外的牌会保留并标明。
- 选卡窗口统一为共享选卡器，提供 8 项筛选和分页；出牌规则加卡时优先列出当前预设的卡，并标出已在手牌中的牌。
- 设置页改为左侧分组导航；外观设置新增“背景光晕”和“减少动态效果”。

## 改进 | Improved

- 回忆、卡组和自定义目标编辑器改为窗口内弹窗，支持 Esc 关闭，关闭后焦点回到原控件；保存格式不变。
- 卡牌名单的卡库按行虚拟化，卡牌较多时滚动与筛选更流畅。
- 首次使用教程适配新的导航与设置页，提示框改用新样式。
- 新界面文案补充英文、日文和繁体中文翻译。

## 修复 | Fix

- 修复后台加载任务时在非界面线程更新任务列表和任务设置，可能引发异常的问题。
- 修复出牌规则页加载时，预设分段控件可能把已保存的预设切回第一项的问题。

---

本版本为测试版（Pre-release），只更换客户端界面，不改动识别阈值、OCR、cards.onnx、MaaFramework 5.13.0、DMM PrintWindow、出牌优先级、战斗等待与培育流程。原有配置按原格式读取和保存；新增的界面设置均以 `UI.Liquid.` 开头。原 Suki 背景样式、背景动画、背景过渡三项设置由“背景光晕”和“减少动态效果”代替，旧值仍保留在配置中。

Windows 安装包在 Linux 上交叉编译；界面以无头渲染方式逐页检查过，尚未在 Windows 实机上完成窗口、DPI 缩放与输入法验证。迁移对照见 [2.2.0 界面迁移清单](https://github.com/Quiter53/MaaGakumasuEX/blob/pre/docs/development/ui-2.2.0-migration.md)。

更新渠道默认仍为“稳定版”；需要试用本版本时，请在设置的“更新”中选择“测试版”，或手动下载。
