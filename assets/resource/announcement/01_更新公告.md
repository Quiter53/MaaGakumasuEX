# 更新公告

# v2.1.0

本版汇总 EX 2.0 系列以来的功能与修复，并加入本轮运行效率优化。

## Highlights

### HIF 与特别指导支持自动自定义

新增「启用自动自定义」与目标编辑器，可按顺序设置目标卡牌及各选项的最终次数。HIF 轮间商店按回血、自定义、购买目标饮料的顺序执行，余额足够且仍有未完成目标时刷新继续；普通特别指导按本节点名额完成自定义。该功能默认关闭，仅处理已强化的目标卡，已有自定义次数计入目标。

### 逐卡规则覆盖更多培育环节

新增「自定义再动」与「最多保留一张」，逐卡排序档位同步用于奖励、换牌、商店与常规回忆比较。HIF 换牌支持用同名旧牌换入已持有的限一目标牌；新增默认开启的「快速命中模式」，找到合规候选后结束换出扫描。

### 常规培育支持再生成回忆

新增默认关闭的「再生成回忆」，每轮最多使用一张再生成票，依次比较钻石词条、获得卡的绿豆数量及卡牌优先级，同分保留原回忆。完善回忆确认与奖励弹窗的衔接，修复结算后停留在贴纸、物品奖励页面的问题。

### 减少培育中的重复识别

优化出牌、饮料奖励与商店的识别调用，同一画面复用已确认结果；日志仅在需要显示图片时读取图像，减少重复计算与图像处理开销。出牌策略、页面等待与交易确认流程沿用原设置。

### Automatic card customization

Configure target cards, their order and final customization counts for HIF interval shops and regular Special Guidance. HIF shops heal first, customize cards, buy target drinks, then refresh when pending targets and the remaining budget allow. This option is disabled by default and only handles upgraded target cards; existing customization counts toward the target.

### Card rules across cultivation

Add per-card extra-action overrides and single-copy preferences, and apply sorting tiers to rewards, exchanges, shops and normal memory comparison. HIF exchanges can replace an owned single-copy target with another copy of the same card. Fast Match Mode is enabled by default and ends the outgoing-card search once an eligible candidate is found.

### Memory regeneration in normal cultivation

The optional memory regeneration setting uses at most one ticket per run. Candidates are compared by diamond traits, green markers on the acquired card and card priority, keeping the original on a tie. Memory confirmation now hands off correctly to sticker and item rewards.

### Less repeated recognition

Reuse confirmed results within the same captured frame during battles, drink rewards and shopping. Log images are fetched only when needed. Existing card policies, page waits and transaction confirmation remain in effect.

## 新增 | New

- 新增自动自定义目标编辑器，支持搜索、筛选目标卡，拖动调整顺序，并分别配置游戏中从左到右各选项的最终次数；按已有进度补足，达到上限的副本自动跳过。
- HIF 轮间商店与普通特别指导支持自动自定义，默认关闭；名额按实体卡计算，同一卡牌的多个选项连续完成，积分不足时保留已完成进度并继续后续流程。
- HIF 第三周行动新增外出、支给与休息，默认选择支给；外出可独立配置第一至第三选项。
- HIF 本战新增「普通商店删牌」开关，默认关闭；普通删牌事件及其他剧本商店沿用原设置。
- 逐卡规则新增「自定义再动」，默认关闭；用于游戏内自定义后获得再动的卡牌，开启后参与出牌、奖励、HIF 换入、咨询购买与常规回忆排序。
- 逐卡规则新增「最多保留一张」，默认关闭；获取时检查已有牌组，优先选择其他非黑名单牌，其他候选均被排除时允许重复；删牌与 HIF 换出优先清理重复副本，保留最后一张。
- 培育新增「快速命中模式」，默认开启；换牌时找到合规的 N、黑名单牌或未受保护的 R 后结束扫描，关闭后比较牌组候选优先级；删牌继续使用精确比较。
- 常规培育新增「再生成回忆」，默认关闭，每轮最多使用一张再生成票；票不足或出现钻石购买提示时继续原结算，中断恢复沿用本轮用票记录。
- 新增任务日志无响应与循环检测，连续 5 分钟无任务日志，或固定日志循环持续 3 分钟且至少重复 30 条时停止任务并提示原因；手动等待期间暂停计时。

## 改进 | Improved

- 逐卡排序档位同步用于奖励选牌、换入换出、商店购买与删除、常规回忆比较；提升档位的 R 卡按设置参与排序，游戏内稀有度保持原样。
- HIF 换牌支持限一目标的同名交换，使用同名可选旧牌换入，持有数量保持不变；旧牌置灰或名称未确认时保留当前牌组。
- 优化持牌检查与培育列表滑动，在卡牌内容区域拖动并于终点停留；已确认持有目标时结束检查，牌库翻页保留必要重叠行。
- 优化自动自定义扫描，已确认列表顶部、底部后结束试滑，首个未完成目标可在当前菜单直接处理，减少重复回顶与菜单往返。
- 优化出牌识别，同一截图内复用卡牌检测结果，减少重复检测；新截图继续重新识别。
- 优化 HIF 商店页面与余额读取，同一截图内复用已确认的商店状态，刷新日志使用本次交易已核实的余额。
- 优化饮料奖励识别，完整识别的饮料行不再重复扫描，部分识别或未知状态继续检查。
- 优化任务日志图片处理，仅在消息包含图片时读取图像；识别开始事件使用缓存截图，减少无关的图像读取。
- 卡库补充新卡与转换卡，现共 456 张，其中转换卡 31 张；同步卡牌名单、出牌规则、饮料触发及回忆选牌的名称与缩略图。
- 调整出牌规则页的按钮、字号、行距与卡图比例，手牌与移除按钮合并显示，多行选卡文字按内容展开。
- 将控制器预设配置移至「设置 → 连接设置」，保留已有 DMM 点击延迟与自动应用行为。
- 设置页新增「输出详细日志」，默认关闭；简洁日志显示出牌耗时，识别参数与异常堆栈保留在文件日志中。
- 调整新用户默认布局，左侧显示任务与说明，中间显示设置，右侧显示完整日志；实时视图默认关闭，启用后与日志上下排列。
- 补齐简中、繁中、英文与日文任务及 EX 页面翻译，统一筛选项、计数、状态与曲线标签。
- 任务结果通知补充执行结果、任务、原因与耗时；用户手动停止、通过热键停止或关闭实例时保留本地提示，取消该次执行的外部结果通知。

## 修复 | Fix

- 修复回忆确认后被贴纸、物品奖励弹窗遮挡，持续等待直到循环检测停止任务的问题。
- 修复再生成回忆选定候选后仍寻找已消失的再生成入口，以及错误提示「本轮未使用再生成票」的问题。
- 修复刷取回忆时将非目标卡的钻石词条误判为目标达成的问题，按目标卡、强化状态与自定义次数核对收集条件。
- 修复回忆标题、页签或按钮短暂漏读导致跳过检查的问题；按页面区域读取，保存后核对实际到达页面。
- 修复追加回合「+N」短暂漏读导致已满足回合条件的卡牌反复暂缓的问题，补充标签字符识别与选中牌复核。
- 修复关闭「启用关注租借」后误取消剧情跳过的问题，结算入口优先处理剧情确认。
- 修复跨商店访问遗留状态导致下一店跳过扫描的问题，同店重入继续保留已处理记录。
- 修复 HIF 回血封顶时正常报价被判为异常的问题，按购买的回血档数核对费用。
- 修复自定义将同一卡牌的多次操作误计为多个名额、达到整卡上限后无法确认结果，以及积分暂未读到就结束处理的问题。
- 修复换牌时将置灰卡纳入换出候选的问题，提交前重新核对可选状态与换出预览。
- 修复从 HIF「差し入れ」领取页继续任务时超时的问题，确认标题与领取按钮后继续培育。
- 修复删牌后被商店评论气泡阻挡、回忆列表受背景动画影响反复滑动，以及饮料取消时重复识别互相冲突的问题。
- 修复歌曲名称中「℃」「°C」等字符差异造成的匹配失败，恢复官服与汉化任务中的自定义歌曲入口。
- 修复任务出错后结果通知误报成功，以及微信服务拒绝请求仍被记录为发送成功的问题。
