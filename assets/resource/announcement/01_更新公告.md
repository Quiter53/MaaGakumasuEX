# 更新公告

# v2.1.3

## 改进 | Improved

- 培育主循环先检查体力槽，再运行出牌检测模型，减少非出牌页面的整帧推理；三选项严格识别与兜底识别复用同帧结果，减少重复模板匹配。
- 奖励、商店购买、喝饮料与失败重试等节点的确认轮询间隔调整为 500 毫秒，保留点击前等待与页面确认。
- 工作选人滑动后按画面稳定情况继续，并复用截图；出牌流程中的动画等待集中为命名常量，默认时间与用户设置保持不变。
- 卡牌目录、卡图指纹与稀有度资源加载失败时增加日志提示，便于定位识别资源问题。

## 修复 | Fix

- 移除新增的 60 秒共享子流程超时守卫，修复不同流程或重新启动任务时继承旧计时、提前退出的问题；统一沿用客户端原有的三分钟循环停止与五分钟无日志停止机制。
- 修复特别指导重置与结束参数被框架序列化后无法进入对应分支的问题，兼容原参数写法并去除重复解析。
- 修复部分高置信度手牌框向右延伸到背景、被尺寸过滤丢弃的问题，对符合尺寸条件的过宽检测框按左边缘裁回标准宽度。
- 补齐 NIA 与 HIF 的饮料丢弃弹窗恢复，保留 NIA 工作选项优先顺序；演出跳过按横屏状态执行，保留原调用点的点击推进。
- 修复弹窗颜色预检查在截图尺寸不足时把未覆盖区域当作无弹窗的问题，无法完整检查时继续原识别流程。

## 其他 | Other

- 整理 Python 与流水线文件格式，补充流程、识别开销和动画等待的回归测试。
- 新增合成手牌离线评估工具，支持使用 Lab 原图检查原检测模型与卡名识别；合成结果不代表实机准确率。

---

本版为预发布测试版，正式版仍为 v2.1.2。请下载完整 Windows x64 便携包，解压到独立测试目录；迁移配置时保留自己的 `appsettings.json`、规则、名单、饮料与任务实例，公共 `config/card_library.json` 使用新版。

保留原 cards.onnx、MaaFramework 5.13.0、DMM PrintWindow 与已有出牌优先级。出牌后等待时间默认仍为 1.5 秒，可沿用个人设置。

已通过 1199 项 Python 测试、1307 项子测试、1036 项客户端停止机制检查，以及三层资源加载与原模型截图回放。测试重点：出牌与黑醋取牌、商店回血与自定义、NIA 特别指导、奖励结算，以及停止后立即重新开始。尚未完成新一轮实机完整培育，本版供实机测试反馈。
