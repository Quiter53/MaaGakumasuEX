# MaaGakumasu EX v2.0.0

MaaGakumasu EX 的首个独立版本，基于 MaaGakumasu 与 MFAAvalonia，保留上游许可证与贡献者信息。

- 原生 Avalonia 出牌规则页：六种职业预设、逐卡使用回合、优先级曲线、稀有度升档、手牌顺序预览。
- 完整卡牌名单、饮料时机与目标饮料策略、HIF 培育、卡牌及卡组回忆收集。
- 删除「眠気」等卡牌后先关闭已确认的商店评论气泡，再等待商品列表，避免页面检测互相等待。
- 回忆扫描只在主卡不在当前画面时滚动；词条扫描结合文字及位置判断是否到底，减少背景动画导致的重复滑动。停止滚动前仍检查新露出的钻石词条。
- 删除规则页的“新建预设”和“管理”按钮，保留已有预设及保存功能。
- 标题统一为 MaaGakumasu EX；关于和更新入口指向 Quiter53/MaaGakumasuEX。使用 GitHub 完整包更新，不使用上游 MirrorChyan 更新源。
- 调试诊断开关确实控制诊断输出与异常截图，因此保留；默认关闭。
- 保留原卡牌 ONNX、MaaFramework 5.13.0、DMM PrintWindow 截图及恢复后的各识别门槛。

## 使用

下载 `MaaGakumasuEX-v2.0.0-win-x64-portable.zip`，解压后运行 `MaaGakumasu.exe`。升级前关闭助手；请保留原有 `config`、`appsettings.json`。发布包不含个人实例、日志、回忆进度或登录凭据。Windows x64，首次使用选择控制器和任务。

## 验证边界

本次包含原生 UI 构建和按钮测试、Python 逻辑回归、历史截图通过真实 MaaFramework 的离线回放、Agent IPC 连接，以及压缩包逐文件哈希和 CRC 校验。此前版本已由用户跑通完整培育；v2.0.0 的两项时序修复尚未完成新一轮实机长跑。

历史测试中有三项断言与当前运行实现不一致，修改前后均失败，记录在本地审计报告；不将这些旧测试描述为全部通过。

## 源码构建

Python 扩展在 `agent/`，流水线和默认数据在 `assets/`，完整原生 UI 源码与许可证在 `native-ui/`。使用 .NET 10 构建 `native-ui/MFAAvalonia/MFAAvalonia.csproj -c Release -r win-x64`，部署 Core DLL 时保持运行包两端的 MaaFramework 5.13.0 一致。

发布流程见 `tools/build_ex_release.py`；上游自动替换 UI 的发布工作流已停用并归档，避免覆盖定制逻辑。


# v1.5.0 更新公告

> [!NOTE]
> 本版本新增「标」与「荆棘之路」活动卡支持，安排工作支持自动选择时长，并持续修复培育与工作流程中的卡住问题。

## 主要更新

- **卡片数据更新**：新增秦谷美铃「喂，我要说了哦。」、紫云清夏(标)、有村麻央(标)、仓本千奈(标)与十王星南(荆棘之路)卡片数据，并将新活动卡设为默认选择，配置推荐效果与属性倾向
- **安排工作**：工作时长新增「自动」选项并设为默认，按开始时间自动选择时长，使收菜所需登录次数最少
- **启动优化**：版本未变化时完全跳过网络操作，日常启动零网络依赖，更快进入任务
- **默认配置**：新增默认配置模板，默认关闭实时视图，避免第三方 UI 导致任务意外终止
- **Linux 适配**：控制器标识由 WlRoots 更名为 Linux，并新增 uinput 屏幕宽高与 EIS socket 路径配置（旧配置需同步修改）
- **界面布局**：新增 MFAAvalonia 主界面布局配置及校验 Schema

## 问题修复

- 修复 NIA 培育失败重试未确认导致流程中断的问题
- 修正删除/复制/变换操作的点击等待机制，降低界面切换未完成时的误触风险
- 更新商店金币识别模板，修复刷新商店后上方出现 new 标记导致的识别失败问题
- 修复安排工作界面切换未完成导致误操作的问题，点击后加入冻结等待
- 修正安排工作说明中的换行格式

> 更新时建议重新下载完整压缩包解压使用，不要直接覆盖替换旧版本文件，避免残留旧资源导致识别异常。
