# 更新公告

# v2.2.0

## 新增 | New

- 客户端界面整体改为液态玻璃风格，全部使用原生控件实现，提供深浅两套主题；默认蓝色主题使用新的强调色，原有颜色主题设置继续生效。
- 任务工作台改为可自由排布的面板：拖动面板标题即可上下叠放或左右分列，拖动过程中实时让位并预览尺寸；分隔条可调整列宽和面板高度，支持最大化与还原、恢复默认布局和键盘移动。布局自动保存，首次启动时迁移旧版布局；实时画面默认关闭，可在工具栏开启。
- 任务设置：培育偶像改为头像选择，选中后在下方选择该偶像的卡片；出牌后额外等待、培育次数等数字项提供加减按钮，同时可手动输入；“使用道具”改为带图片的道具卡片，选中状态清楚可见。
- 出牌规则页新增“新建预设”“管理预设”、规则搜索、曲线模板、折线/阶梯两种模式、节点精确编辑，以及可选的“总回合数”；手牌模拟的回合范围跟随总回合数，可移除手牌，回合外的牌会保留并标明。
- 选卡窗口统一为共享选卡器，提供 8 项筛选和分页；出牌规则加卡时优先列出当前预设的卡，并标出已在手牌中的牌。
- 设置页改为左侧分组导航（界面设置、配置管理、定时任务、性能设置、运行设置、连接设置、启动设置、通知设置、快捷键、版本更新、关于）；界面设置新增“背景光晕”“光晕流动”和“减少动态效果”。

## 改进 | Improved

- 偶像选择显示完整姓名，去除上课选项分隔线和自动化区域的重复标题；手牌模拟只显示卡图与规则结果，说明文字改为悬停提示。
- 卡牌使用独立裁切的稀有度边框，SSR 虹彩、SR 金色，悬停时提供轻微缩放和光泽反馈；卡牌拖动图像居中跟随指针。
- 任务排序增加实时让位、边缘滚动和 Esc 取消，运行期间继续禁止调整顺序；补齐任务及选项说明，问号提示使用带模糊背景的玻璃气泡。
- 版本更新页统一玻璃面板与设置行，调整下拉框边界、滑条圆形拖柄及节点编辑折叠框；移除“实时自动保存”提示，保存行为不变。

- 开始培育的设置按设计原型重新分组，补齐策略快捷入口、两列道具卡片与自动化编队区域；窄面板自动换行，现有选项和保存格式继续保留。
- 普通按钮、偶像头像和状态徽章统一玻璃反馈，侧栏选中气泡移动更利落，等待时间改为一体式加减控件。

- 窗口的最小化、最大化和关闭按钮移到标题右侧独立的按钮组，关闭按钮悬停变红；置顶按钮保留在标题栏右端。
- 回忆、卡组和自定义目标编辑器改为窗口内弹窗，支持 Esc 关闭，关闭后焦点回到原控件；保存格式不变。
- 下拉列表、菜单和提示使用不透明的底色，文字清楚；页面玻璃略微更通透。
- 任务设置在窄面板中自动把名称放到控件上方；卡牌名单的筛选栏放不下时自动换行。
- 卡牌名单的卡库按行虚拟化，卡牌较多时滚动与筛选更流畅。
- 首次使用教程适配新的导航与设置页，提示框改用新样式。
- 界面中的程序名称统一为 MaaGakumasuEX；新界面文案补充英文、日文和繁体中文翻译。
- 连接时如果没有选择模拟器设备或游戏窗口，会直接提示刷新并重新选择。
- 更新检查合并同时发起的请求；遇到 GitHub 访问频率限制时，在限制解除前不再重复请求。

## 修复 | Fix

- 修复拖动字体比例时界面缩成窄面板、两侧留白，以及部分文字重复放大的问题；按当前视口重新计算逻辑布局，并统一只缩放一次。
- 修复切换选项后选中气泡延迟出现的问题，首次布局立即定位，后续切换保留过渡。
- 移除卡牌删除时的截图离场动画，避免残留放大或错位图片；修复卡图覆盖稀有度边框四角的问题。

- 修复弹窗背景更新时旧图片提前释放，可能造成原生渲染崩溃的问题。

- 修复任务选项切换后，旧控件的延迟布局测量可能触发 RootPanel 异常的问题。
- 修复移除卡牌时离场图片在缩放后放大、裁切或错位的问题。
- 修复普通面板占用模糊背景快照，导致弹窗沿用旧页面背景的问题，减少无模糊面板的截图开销。
- 修复任务行和头像叠加矩形选中底色，以及普通、高级混合任务的高级设置页空白的问题。

- 修复下拉列表展开后只显示当前选项、其余选项不可见的问题。
- 修复切换选项或调整窗口时，分段选择控件可能报错（Invalid unit: E-05px）的问题。
- 修复卡库中的卡牌无法拖入黑名单、白名单或替换名单的问题。
- 修复圆角按钮下方出现直角色块的问题。
- 修复打开弹窗时背景出现线条闪烁和方块残影、快速重开弹窗时背景短暂未模糊的问题。
- 修复启动时重复加载实例导致实例配置保存时报“文件被占用”的问题；配置改为原子写入，较旧的内容不会覆盖较新的内容。
- 修复工作台拖动面板时，键盘焦点不在工作台内则按 Esc 无法取消的问题。
- 修复出牌规则“生效回合窗口”在较窄窗口中被挤压的问题，以及开关被整体放大、与其他控件不对齐的问题。
- 修复后台加载任务时在非界面线程更新任务列表和任务设置，可能引发异常的问题。
- 修复出牌规则页加载时，预设分段控件可能把已保存的预设切回第一项的问题。

---

本版本为测试版（Pre-release），只更换客户端界面，不改动识别阈值、OCR、cards.onnx、MaaFramework 5.13.0、DMM PrintWindow、出牌优先级、战斗等待与培育流程。原有配置按原格式读取和保存，新增的界面设置均以 `UI.Liquid.` 开头。旧版的背景样式、背景动画、背景过渡设置只要改过，就会对应迁移到“背景光晕”“光晕流动”“减少动态效果”，旧值仍保留在配置中。

本轮提供本机构建的 Windows 测试包，并运行原生规则、配置、饮料、卡牌名单、任务选项和布局动效回归。Windows CI 继续检查打包、深浅主题、窗口尺寸、配置重启和交互；最新执行状态见仓库 Actions。完整实机培育、中文输入法和自动更新升级全过程仍待验证。修复原因及验证范围见 [第四轮记录](https://github.com/Quiter53/MaaGakumasuEX/blob/pre/docs/development/ui-2.2.0-round4.md)。

更新渠道默认仍为“稳定版”；需要试用本版本时，请在设置的“版本更新”中选择“测试版”，或手动下载。
