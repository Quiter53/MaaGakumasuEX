# 官方 v1.5.2 合并记录

合并日期：2026-10-10。定制基线：`d08dd1a`；上游：`3f3d37995ab612a9c725fc86cba4cacef09ed335`。
回退分支：`backup/pre-upstream-1.5.2-20261010`。本次只合并源码，不部署现有便携目录，不打包、不发布。

## 合并范围

- 按用户最终要求，战斗与列表均保留定制版原检测模型，不采用官方新模型。保留定制的再动/稀有度优先、同档推荐优先、跨帧无牌复核与断线恢复。
- 处理顺序统一为先过滤手牌区域再处理可用/不可用结果。15 秒仍无完整候选时，只尝试当前帧高置信度残缺可用牌；45 秒没有可用依据时返回失败并保留现场，不盲点、不跳回合。
- 接入自定义歌曲及第一/第二属性、推荐效果配置，新增 Me、Agitato 卡片与偶像/歌曲 OCR 归一化。
- 合入日常金币扭蛋、每日兑换、笔记红蓝对应、工作时长、社团阈值及 NIA 强化回跳修复。
- `ProduceComplete` 仅从已识别主页的 `ProduceBackHome` 结算节点进入，在 `ProduceLoop` 次数耗尽后正常结束；任务中途不使用该节点兜底。
- 合入 Agent 版本文件多路径查找，保留已有框架版本锁定与启动兼容保护。

## 不直接覆盖的部分

- 保留 HIF 课程/SP 优先级、两阶段上课、轮间商店、名单预设、奖励饮料、删除/替换优先级与次数管理。
- 保留 `PrintWindow` 截图方式、现有安装发布工作流、依赖版本、用户配置和持久测试目录。
- 上游新增 `/tests/` 忽略及删除测试指引不适用于本分支。
- 官方新模型在历史 HIF 换牌列表截图上出现更多漏检。合并时曾分离战斗/列表模型，随后按用户要求全部恢复为原 `cards.onnx`，移除双模型路由与冗余副本。原模型 Git 对象：`c443c4e14c96309a296e4b269484b34d6c0fcf51`，新增测试固定校验其内容。
- 自定义歌曲推荐效果不会自动切换用户名单预设，也不代表新增了最优出牌策略。
