# v1.5.0 定制版

基于官方 MaaGakumasu v1.5.0 合并，保留定制界面、黑白名单、奖励卡牌策略、饮料策略、HIF 选项、换日与网络恢复及奖励次数预算。

## 更新内容

- 合入官方 v1.4.8 至 v1.5.0 的新增偶像、偶像之路、自动支援卡、工作时长选择、流程确认和模板修复。
- 保留定制版再动与稀有度出牌策略，限制异常手牌框的纵向范围。
- 合入官方 NIA 失败重试确认与支援卡替换流程，同时保留断线恢复入口。
- 界面端与 Python Agent 统一使用 MaaFramework 5.13.0，依赖固定为 maafw==5.13.0。
- 启动时核对已安装依赖版本；即使资源版本没有变化，依赖不匹配也不会直接跳过。
- 兼容附加实例参数的 Agent 启动命令。

## 使用与回退

新版使用独立目录，原目录与 v1.4.8 压缩包保留。完整解压后运行 MaaGakumasu.exe。DMM 游戏以管理员权限运行时，助手也需要相同权限。

保留当前任务、黑白名单与控制器预设，调试诊断默认关闭。界面使用定制版构建，以保留黑白名单设置页；不是直接替换成官方通用界面程序。

## 验证范围

31 项单元测试、官服/汉化/DMM 三层资源加载通过。历史奖励样本中饮料页命中、卡牌页未误判为饮料。5.13.0 客户端与实际 Agent 握手成功，注册 23 个自定义动作、9 个识别器，并正常退出。完整实机培育需另外验证。
