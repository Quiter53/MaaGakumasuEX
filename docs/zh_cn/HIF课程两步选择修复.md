# HIF 课程两步选择修复

## 设置与流程

HIF 本战的授业使用“上课属性”和其下的“上课选项”。课程与公开课程按六级顺序选择：第一属性 SP → 第二属性 SP → 第三属性 SP → 第一属性普通课程 → 第二属性普通课程 → 第三属性普通课程。第一、第二、第三属性取自偶像的属性偏好配置；只比较当前可用课程，SP 优先用于获取星耀值。课程选择不受属性数值比例或老师建议影响，也不依赖三属性数值、体力与积分 OCR。后续回答选项使用“上课选项”。初、NIA 的事件策略独立运行。

每日入口使用完整的“授業 / 公開レッスン / レッスン”标签及图块内属性图标联合识别。课程标签兼容 `Vo./Da./Vi.` 前缀、半角/全角句点、中点及分隔空格；位置限定在每日入口区域。带前缀的课程同时校验图块中央属性图标与文字属性一致，采样区域避开共同奖励星标和 SP 标记。无前缀入口继续使用相邻属性徽标。点击配置对应的属性后，继续处理属性横条和回答选项。卡牌效果描述中的“レッスン中1回”不构成课程入口。

主流程的 `ProduceHIFChoicesFlag` 可从三选项及效果预览页面直接继续，按左上角的授業/レッスン标识分流到相应策略。专用识别校验三条横条、上下间距、属性文字颜色。混合属性横条进入属性选择，三个同属性横条进入选项选择。支持宽度 720、高度 1278～1282 的框架截图取整差异。

选项中心取自当前识别框，两次观察的位置一致才点击；日程入口也在位置稳定后读取 SP 并决定属性，选定属性继续用于后续属性选择步骤。效果预览保留三选项状态：选中项显示属性色填充，其余两项变暗；重新观察稳定后点击设置的选项进行确认。仅在页面实际变化且连续两帧退出三选项后记录生效。每阶段最多点击三次，超时或达到次数上限返回动作失败，保留现场；停止任务和通信错误会中断处理。

## 咨询日程入口

HIF 的绿色“相談”日程图块与商店内部使用不同的识别入口。日程入口须同时命中完整标签、图块位置与大面积绿色图标；稳定后点击图块中心，最多三次、14 秒，并以连续两帧页面变化确认推进。停止任务和通信错误会中断处理。

进入商店后由已有 `ProduceHIFShopFlag` 执行当前自动咨询或手动接管设置。黑白名单、删牌优先级和饮料购买策略保持原有逻辑。

## 换卡流程

`ProduceHIFChangeFlag` 识别专用“チェンジで獲得するスキルカード”提示与三张方形卡牌。换入牌沿用普通选牌评分：避开黑名单，优先白名单，再按再动与稀有度选择。启用的“次へ”按钮须同时通过文字与橙色填充校验；后续页面须重新识别。

换出牌与商店共用 N → 黑名单 → R → 替换名单优先级。替换名单内 SR 优先于 SSR；明确加入替换名单的牌允许换出，即使它也在白名单。其余白名单牌受保护。专用入口校验“チェンジ”顶栏及牌组选择提示，优先于通用删除/复制/变换节点。候选必须位于牌组网格内且卡框完整；上方换入牌及网格边缘的半张卡不参与选择。

牌组先连续观察卡框位置与牌面，按唯一空间位置对应比较两帧，允许 3 像素以内的检测抖动。卡框缺失、移动或牌面变化继续等待；稳定后执行一次牌面识别，再进入详情核实。稳定性校验覆盖当前完整候选牌，不依赖卡牌数量或检测返回顺序。连续五次未稳定时记录明确原因并保留现场。

当前页出现已确认的 N 卡时直接选择；否则继续下划寻找，最多扫描六页，扫描预算为 90 秒，画面不再变化即结束扫描。跨页比较完整删除优先级，包含替换名单的 SR/SSR 次序。返回目标页面后重新识别卡牌身份与坐标。提交要求“チェンジ”按钮文字和亮橙色状态同时命中，并观察页面实际推进。实机换出 N「思考の基本」并提交后，已进入支给及后续奖励流程。
