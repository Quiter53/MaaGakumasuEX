# HIF 商店目标饮料与失败收尾

## 购买策略

普通商店删卡顺序为 N → 黑名单 → R → 替换名单，替换名单内 SR 优先于 SSR。明确加入替换名单的牌允许删除，即使它也在白名单；其余白名单受保护。网格候选使用卡图数据库与卡框识别，逐个点开完整卡框的详情，以连续两帧精确卡名匹配数据库后参与跨页排序。已核实 N 卡可立即结束扫描，其余优先级需确认牌库底部；跨页选定后重新寻找同名卡框并核对详情。任意页仍有身份未核实的卡时，暂停低优先级删除或换出，保留现场。白名单买卡优先级保持不变。饮料只购买特製ハツボシエキス、初星黒酢、初星湯、ブーストエキス、センブリソーダ、初星ホエイプロテイン，候选中按实际售价从低到高选择。积分或价格未读到时不购买。

删除按钮使用原有模板定位，限定底部区域、匹配分数及启用颜色，精确文字识别作为补充。删除确认需核对“スキルカード削除”标题、删除问题、同一张卡名、余额减少预览、删除与取消按钮；问题与卡名区域按弹窗标题位置定位，适应不同卡片说明长度。连续两帧一致后提交一次，随后连续两帧确认最终余额才记成功。HIF 残留删除弹窗恢复时先取消并重新按全局优先级选择；同次店内恢复完成后继续购买流程。HIF 换出牌共用上述扫描及详情核实规则。

普通日志显示每页候选数、未确认数、本页及全局最优、最终选择、提交结果和停止翻页原因。找到已核实 N 卡时结束搜索；没有 N 卡时实际翻页，直到牌库图像不再移动，再按跨页优先级选择。HIF 换出完整卡框区域覆盖 y=620～1100，包含实际首排 y=635～637，排除上方目标卡和页脚。逐卡框、匹配置信度及详情探测结果保留在调试文件中。

商品先在对应饮料格内做图像匹配。购买饮料前连续两帧确认栏位：未满时购买六种目标中实际售价最低且可负担的饮料，允许购买已有同种。满栏时核实四瓶持有饮料，库存中有可负担目标且持有非目标时，丢弃一瓶已确认的非目标后购买；四瓶均为目标则保留现状。没有可负担目标时保留饮料和积分，普通商店结束饮料购买，为轮间购买保留预算。点击后核对商品名称，交换确认框再核对一次名称和标题。扣款未核实就停止本次购买，不重复提交；确认购买后重新检查栏位。普通商店删卡与白名单买卡不受饮料栏满影响。

普通商店和轮间商店按各自八格布局，连续两帧库存稳定后再扫描。HIF 普通商店联合确认两排各至少三个价格底色与准确位置的黄色 P 图标，轮间商店使用独立布局识别。支援物品的获得效果遮挡商品时，只在商店标题已确认的情况下限次点击空白标题区，避免将弹层视为无目标库存。购买与刷新要连续两帧确认最终扣款，排除积分动画中间值。

商店未满栏时只读取栏位是否占用；满栏时逐瓶读取详情并连续两帧核实精确名称，保护未确认饮料。只为已识别且可负担的目标商品腾位，丢弃一次后重新确认三瓶占用再购买。名称、丢弃确认或栏位减少未核实时保留现场。

持有名称按 P ドリンク詳細标题定位到名称行，连续两帧核实；商品价格、面板标题与效果文字不作为饮料名称。丢弃确认按廃棄確認标题定位问题，核对完整同名问题与按钮，连续两帧核实后提交一次，再确认栏位减少。

获得重复目标奖励时，先丢弃已有同名饮料，再领取一瓶奖励，满栏与未满栏规则一致。连续丢弃时重新读取移动后的栏位，保留其他种类；识别或丢弃未确认则跳过该重复奖励。

奖励页与持有栏逐格识别六种目标饮料，避免同类瓶子的匹配结果互相覆盖。满栏领取当前没有的目标时，优先点开非目标候选，核实其名称不属于六种目标后丢弃，再领取目标。已勾选“不领取”的页面仍进入奖励策略，领取前解除勾选；需要跳过时保持勾选并提交。

## 普通商店转场与退出

HIF 通用按钮只处理下一步、开始、关闭和确认等操作；商店结束按钮由商店策略在购买结束后处理。商品页两帧稳定即可继续，每次就绪检查最多观察十帧、帧间等待 0.25 秒，遮挡最多清理两次。

购买或删卡后先确认商品页仍在。需要重进时，最多观察六帧；咨询桌顶部标题与交换文字连续两帧位置一致后，点击实际识别框中心一次。已进入试镜或其他培育页面时交回主循环继续识别。商品区持续不稳定、购买身份或扣款未知属于未确认状态，保留现场。

普通日志在商品稳定后显示商店策略，评论气泡关闭提示每次处理显示一次。内部标题探测静默，重试与转场观察写入调试文件。

## 本战轮间商店

Round1 后的 `インターバル` 商店有六张卡、两瓶饮料；第二排左侧两格是卡，右侧两格才是饮料。独立识别布局，不沿用普通商店的四饮料格，也不点击该页不存在的删卡入口。

标题 OCR 被拆开时，使用商品价格区、退出按钮模板、卡牌定制文字和刷新文字联合确认轮间布局。普通商店入口也在扫描前重新核实并转交轮间策略。

栏位未满或满栏持有已确认非目标、且库存没有目标饮料时，读取左下刷新按钮及其当前费用，保留饮料寻找目标。刷新后必须同时确认库存变化和对应积分扣除才计数。保留至少 75 积分用于买目标饮料；积分不足、费用未知或满栏四瓶均为目标时退出。单店最多确认 32 次刷新，防止异常循环。

价格识别接受单独数字及货币图标合并的 `P 100`；折扣取右侧实际售价。目标价格或余额未知时最多重读三次，仍未知则保留现场并报告动作失败，不按积分不足退出。确认购买的格位在本次库存内屏蔽，刷新成功后重新扫描。购买后重新检查栏位与满栏身份；仍有空间或已确认非目标时继续购买、刷新寻找目标。

## 本战失败收尾

本战 R2 失败后选择“次へ”，出现“再挑戦確認”时点击左侧“プロデュース終了”，继续奖励、生成回忆与返回主页流程。不会点击右侧再挑战。选拔、初、NIA 的原有失败策略保持不变。

失败动作由本战专用入口路由，不使用保存设置的 `ProduceHIFStrategy.enabled` 判断剧本；该配置节点默认禁用，不代表本战策略关闭。

## 培育次数边界

次数按一次任务中进入或继续的培育局数限制，当前局续跑计入一次；本战 R2 失败后结束并完成结算也计入一次，不以试镜获胜为条件。演出结束、回忆生成、完成按钮三个结算出口均经 `ProduceBackHome → ProduceLoop` 检查次数，再决定是否准备下一局和补充 AP。网络重试或返回标题后恢复当前局经培育入口继续，不经过次数循环。手动重新开始任务会重建本次任务计数；选择无限次数并开启体力药时可以继续消耗 AP 饮料。

## 本战开始确认

HIF 本战准备阶段直接进入“開始確認”，不再经过普通剧本的支援卡选择。旧路线在 `ProduceChooseIdolNext` 后只等待 `ProduceChooseSupport`，实机于 20:31:33 超时 20 秒，任务返回失败而界面显示“全部完成”。

本战任务启动后，在用户设置合并完成的路线中加入开始确认页识别，兼容 MaaFramework 返回的结构化 `next`，保留网络恢复优先级和道具开关。首页优先识别首页，不被跳过准备的无条件入口截走。准备页同时确认顶部“開始確認”和底部“プロデュース開始”，再按现有道具设置进入本战。培育主循环不再检测开始页，避免转场残帧重复启动。任务从局内重新开始时，用明确的授业、课程、奖励、商店等页面识别接回当前局，不要求打开跳过准备，不使用通用下一步或无条件节点确认状态。
