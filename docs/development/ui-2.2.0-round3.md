# v2.2.0 第三轮界面修复

样式基准为 Lab `a0a7681` 的 `ui-prototypes/modern-preview/MaaGakumasu-UI-Modern-Preview.html`；基于 pre `fc31a67` 修复。全部使用 Avalonia 原生控件。

## 原因与修改

| 现象 | 原因与处理 |
| --- | --- |
| 开始培育仍是通用选项堆叠 | 两条设置入口统一使用培育分组布局：难度、头像及偶像卡级联、模式及其目标、三个策略入口、等待时间和两列道具、自动化与编队。继续使用原选项创建、校验、保存和 pipeline_override；未归类的新选项继续显示。 |
| 头像悬停方形底色、任务行矩形叠层 | 控件主题和通用列表样式在 ContentPresenter 上重复绘制状态背景。玻璃控件只由圆角表面负责填色；头像有浮起、按压、边缘光和选中头像环反馈。 |
| 按钮只有变色、状态文字悬空 | 统一普通按钮的浮起/按压和回弹；状态文字包入玻璃徽章；等待时间使用一体式步进器。 |
| 切换选项时报 RootPanel 异常 | 日志调用链经过任务布局的延迟 NaturalWidth 回调，旧控件移除后仍可能被测量并重新应用模板。删除这条 SizeChanged/Dispatcher 测量路径，改为正常布局周期内的 ResponsiveOptionGrid。没有吞掉 SukiUI 的异常或修改其内部模板。 |
| 移除卡牌出现放大、裁切的残影 | 离场快照和浮层使用不同坐标系。快照保存控件局部内容，浮层保留完整源到目标变换；离场变换应用到独立图层，动画结束释放图片。 |
| 弹窗背景可能不是当前页面 | 半径为零的普通面板、隐藏的弹窗遮罩也注册了背景使用者，使首张快照一直存活。只登记启用模糊且可见的层；关闭动画结束释放登记，下次弹窗重新捕获当前页面。 |
| 侧栏气泡拖沓 | 缩短到 180ms，显式设置初始变换，保留原有页面复用；移动通过变换完成，不逐帧重建页面。 |
| 高级设置页空白 | 普通/高级混合任务的生成分支错置。混合任务分别生成两页，只有高级项的任务在唯一设置页显示。 |

## 验证与范围

- Python 回归：1261 项通过、1310 项子测试通过；首次跳过的原生数学等价性在生成 3600 组原生向量后补跑通过。
- 原生规则 620 项、配置保存 11 项、发布策略 25 项、任务 watchdog/结果 1036 项检查通过；饮料和卡牌名单测试通过。
- LiquidBoardTests 覆盖布局、重排、窄宽切换、移除及重新挂载、字体缩放 1/1.25/1.5 下快照坐标与像素、透明圆角、背景更新、关闭按钮颜色和减少动态效果。
- NativeShots 的 taskopts 覆盖实际培育入口的分组、头像级联、等待值与边界、道具保存、重复切换任务，以及普通/高级两页与高级单页的显示和保存。已加入 Windows CI。
- UiVerification 记录导航动画的窗口帧回调间隔，独立于截图等待时间；这是性能诊断，不把它等同于所有电脑的显示帧率。
- 本地两次桌面输入自动化未全部通过（关闭按钮悬停，以及随后一轮的卡库点击/拖动和失去可视树的弹层引用），不作为通过证据。按用户要求停止 Computer Use 和本机鼠标键盘驱动；后续使用原生控件测试、非交互截图检查及隔离 Windows CI。
- `agent/`、任务定义和识别模型与 v2.1.5 相同。本轮没有执行新一轮完整实机培育，也没有验证中文输入法和自动更新升级全过程。

本轮只更新 pre/v2.2.0 测试包。正式版 main、Latest 和本机 latest 保持 v2.1.5。
