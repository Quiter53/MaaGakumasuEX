# 识别耗时与出牌等待

## 本轮修改

在培育（含汉化）及偶像之路任务中加入「出牌后等待时间」，默认 1.5 秒，范围 0～5 秒。使用原生任务单行输入控件，说明位于输入项提示中；配置键保留为「出牌后额外等待」。通过 `ProduceCardsFlag` / `IdolRoadAuto` 的 `custom_action_param.post_play_delay` 传入共用出牌动作，每次调用重新读取。旧配置和无效值保持 1.5 秒。

等待仍位于确认提交成功、`_wait_until_playable(require_hand_stable=True)` 成功之后。0 只取消这一段额外等待。未修改选牌规则、饮料策略、识别阈值、选中与提交复核、动画轮询间隔或三分钟无进展停止机制。

## 优化顺序

1. 已实现：用户可减少出牌后固定额外等待。从 1.5 改为 0.5，每次实际进入这段等待少等 1 秒。这是等待时长差值，未测得整场游戏提速比例。
2. 待验证：通用按钮在 720×500 区域匹配 8 个模板；未命中时尤其耗时。可按已确认场景分组或给各按钮明确 ROI，但需要不同界面和动画帧的正负样本回放，避免漏掉取消、关闭和结束按钮。本轮保持原识别。
3. 待验证：回忆、商店和弹窗 OCR 可检查同一截图内的重复调用，按相同用途复用一次结果。跨截图缓存、减少确认帧数会改变行为，本轮未采用。
4. 原卡牌模型平均约 14 ms，收益优先级低。本轮保留原模型和运行后端。

原「出牌点击已观察 耗时」日志打印在等待动画和额外等待之前，不能当作两次出牌之间的完整用时。
