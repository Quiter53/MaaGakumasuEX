# v2.2.0 第四轮界面修复

## 原因与处理

- **字体比例导致两侧留白**：根布局使用布局变换，测量与变换后的尺寸相互影响；比例变化时还分别写入 X/Y 缩放，出现中间状态。改为 `UniformScaleHost`：以当前视口除以比例测量、排列内容，统一变换并把 Margin 位移计入。FontService 一次更新独立窗口的两轴变换；字号资源保持逻辑尺寸，避免整体布局和字体资源重复放大。
- **选中气泡迟到**：原分段控件排队更新位置和恢复过渡。现在在当前布局中直接定位，第一次展示不播放移动，之后才过渡。
- **卡图四角缺色**：图片覆盖了同层圆角边框。把图片放入独立内层圆角裁切，外围保留完整稀有度渐变。悬停光泽由指针事件驱动，不使用常驻计时器。
- **卡牌拖动偏移**：拖影的位置和指针统一使用 OverlayLayer 坐标，卡图居中于指针；拖动结束在 finally 中解除事件并移除浮层。卡牌删除直接刷新列表，不再生成截图离场动画。
- **任务拖动没有让位反馈**：预览只调整行的渲染位移，松手才调用原有 MoveTo 修改一次集合。保留运行中禁止排序；Esc、捕获丢失、尺寸变化、数据源切换均清理预览；列表边缘滚动只在拖动时启动计时器。
- **提示内容空泛**：部分中文翻译值仍为“某某说明”的占位符，部分任务无 doc。补充真实说明；问号内容使用窗口内模糊玻璃 Popup，脱离视觉树时关闭并解绑。
- **控件方形残留与风格不一**：下拉和滑条模板隔离旧主题部件选择器；滑条用圆形几何图元绘制拖柄与光晕。更新页改用同一 GlassPanel、SettingRow，保留原命令、更新渠道和配置绑定。

## 保留与简化

保留配置字段、任务入口、OCR、识别模型、出牌规则、饮料策略、更新渠道和自动保存行为。删除的“实时自动保存”只是提示文字。删除两段常驻规则解释后，以悬停提示保留含义。偶像显示全名，手牌模拟去掉常驻卡名，卡名仍可悬停查看。

## 验证方法

`tests/NativeShots` 的 `round4` 使用 Avalonia Headless 与 Skia，不操作桌面鼠标键盘：

- 多窗口尺寸、80%～150% 比例往返；校验内容及缩放后边距填满当前视口。
- 合成指针拖动字体滑条，验证值确实变化、布局持续填满视口。
- 任务拖动让位、落点、Esc 取消及长列表边缘滚动。
- 当前布局帧选中气泡可见、问号实际内容与模糊背景、精确编辑展开。
- 浅色及深色页面渲染截图。

`LiquidBoardTests` 检查卡框四角像素、拖影坐标及移除、窗口布局和动画。原有 CardRulesUi、DrinkUi、CardListUi、ConfigSaveTests、ReleasePolicy 和任务选项检查继续运行；CardRulesUi 改为检查按需提示，符合删除常驻说明的要求。Windows CI 同时执行 round4，打包、隔离 runner 窗口交互及配置重启验证沿用原流程。

本机实测结果：规则 620 项及 3,600 组策略向量通过，布局与动效 7,700 项通过，配置保存 11 项、发布渠道 25 项通过；饮料、卡牌名单、任务选项和 round4 检查均通过。

真实游戏完整培育、中文输入法及自动更新升级全过程仍待实机验证。Headless 渲染验证不代表目标云电脑帧率测试。
