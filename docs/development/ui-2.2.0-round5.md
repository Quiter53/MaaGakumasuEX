# v2.2.0 第五轮：圆角裁切与迁移审查

正式版对照为 v2.1.5。离线测试使用独立配置和 Lab 夹具，不修改用户运行目录；Headless 事件仅作用于测试窗口，不控制本机桌面。

## 修复原因

- 滑条内部虽为圆形，外层 Thumb 会裁切超出的光晕。将容器扩展至 26×26，内圆保留 22×22，光晕在容器内绘制，关闭外层裁切。
- 输入和选择控件的 DataValidationErrors 模板层会矩形裁切阴影，取消该层裁切；浅色输入、滑块和按钮悬停阴影改为白色光晕。深色主题保留低透明度阴影。
- 卡库第一行的悬停位移越过列表顶部。给列表留出 6px 空间、每张卡在行内保留 4px 上下余量，列数计算同步扣除边距；顶部预设与名单选择在放大时自动换行。
- 说明气泡继承 Markdown 段落的顶部边距，在气泡内覆盖为零；道具说明只有图片时不再额外显示问号，有实际文字的说明继续保留。
- 饮料采用共享 CardArtwork 边框、缩放和指针光泽反馈。移除常驻操作说明，保存成功简化为“已保存”，读取和保存失败仍显示原因。
- 下拉框搜索或重建时会短暂清空选择，旧回调将 SelectedIndex=-1 写入任务选项。现在仅接受真实 case，并按其名称映射回原始索引；临时空选择不再污染配置。

- 指向当前主仓库源码运行：1262 项测试、1310 项子测试通过。
- 历史手牌 34 次身份识别全部正确。
