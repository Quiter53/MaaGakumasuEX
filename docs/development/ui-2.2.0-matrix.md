# 2.2.0 原生界面迁移矩阵（第二轮）

对照基准：正式版 v2.1.5（`d08174d`）为业务基准，Lab 原型 `a0a7681`（含 README 第二～五轮、AVALONIA-NATIVE.md）为视觉与交互基准。

“验证”一列的缩写：
- **W**：GitHub windows-latest 真实窗口（UiVerification；`--ui-verify-interactive` 为 SendInput 真实鼠标键盘）。
- **H**：Linux 无头渲染或无头真实输入管线（NativeShots / 测试项目）。
- **T**：自动化测试（CardRulesUi、CardListUi、DrinkUi、LiquidBoardTests、ConfigSaveTests、ReleasePolicy、pytest）。
- **—**：未验证。

状态：✅ 完成；◐ 完成但有限制（见备注）；✗ 未完成。“原型无”表示原型未覆盖、按同一设计体系补齐的正式功能。
