# 控制器配置移至连接设置

任务列表原来把控制器选项包装成置顶配置行，外观容易被误解为可执行任务。实际上，执行任务过滤器一直排除这类配置项，`MaaProcessor.MergeControllerOptionParams` 会自动合并当前控制器参数。

本次将入口移至原生“设置 → 连接设置”，不再在任务列表创建控制器配置行。当前 PC 控制器提供 DMM 点击延迟，范围仍为 0～1000 毫秒。没有选项的控制器不显示该卡片。

界面复用现有选项渲染器和输入校验，继续读写实例的 `ControllerOptionItems`，保留旧值及其他控制器设置。连接设置与执行参数使用同一组选项对象，任务运行中禁止编辑；语言和当前实例切换会刷新面板。培育、识别和参数合并逻辑没有改动。

验证：原生构建成功；760 项 Python 测试、339 个子测试通过；原生 570 项检查、3600 组策略向量通过。其中新增 13 项检查覆盖旧配置行移除、旧值恢复、参数共享、实际输入修改与保存、运行锁定及控制器切换。实际连接配置卡片已在亮色和暗色主题下渲染检查。测试使用隔离配置，未操作游戏，未执行新的实机培育。
