# 常规培育：再生成回忆

在“培育模式 → 常规培育”下新增原生开关“再生成回忆”，默认关闭，与培育次数同级。官服、汉化任务及四种界面语言均已加入。旧任务未保存该选项时默认关闭；设置沿用原生任务选项的保存机制。

关闭时继续现有生成/保存回忆流程。开启后，每轮最多进行一次票券再生成，然后比较原回忆与新回忆：

1. 有钻石词条优先。
2. 钻石情况相同时，获得卡的绿豆数量更多者优先。
3. 绿豆相同，再动优先；同为再动或同为非再动时，稀有度更高者优先。
4. 完全相同保留原回忆。

比较的是“获得可能技能卡”，不是 Stage 六张卡组或 HIF 能力卡。没有增加强化状态、自定义出牌曲线等未指定的排序条件。

票不足、出现钻石购买提示时退出再生成，继续结算。关键字段读取不全时有限复核，仍读不到则保留当前候选继续，不把未知绿豆或钻石状态当作零。相同票券确认窗口迟迟不消失时不会再次提交消费；流程可交回识别继续等待。中断后从候选页恢复，不会再花一张票。

常规培育仍按用户的培育次数运行。返回主页后清理本轮比较和消费状态，下一轮重新计次。刷取卡牌回忆、刷取卡组继续使用原来的目标策略与循环设置。
