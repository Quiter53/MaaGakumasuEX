# 卡组回忆判定与流程复核

## 目标含义

卡组模式要求同一份回忆同时包含全部已选目标。角色卡、支援卡分别限定来源；第 3～6 格的普通卡按无序集合匹配，不要求游戏中的排列顺序与配置位置相同。空格不参与匹配，重复填写同名卡需要相应数量的实体副本，不能把不同候选或不同轮次的部分结果拼成一份达标卡组。

本次用户配置为：シュプレヒコール 已强化、願いの力 已强化且绿豆至少 2、脚光 已强化且绿豆至少 1。角色卡、支援卡与其余普通卡没有目标限制。绿豆 0 表示不限制数量，强化要求独立生效。

## 复现与修复

- Stage 页签点击未生效时，旧代码仍会滑动原来的 Produce 页。真实截图加虚拟丢失点击复现后，改为先确认 Stage 已选中，再读取或滑动；下次复核重新定位并点击。
- 滑动后及第二帧复核前，旧代码未检查页面类型和候选序号。现在页面或候选改变就退出本次观察，保留流程状态，避免在新页面继续旧操作。
- Stage 灰置时，旧代码单帧便判断没有卡组。现在用新截图复核灰置状态；确认无卡组仍属于目标未达标，启用再生成时沿用原有用票流程，不因缺少卡组而提前保存退出。
- 无卡组候选按未达标评分，避免与达标卡组同分时误选回无卡组结果。
- 已有足够的合格副本时，另一张同名卡的未知强化/绿豆不再否决整组达标。原有一对一匹配仍要求重复目标各有独立合格副本。
- 对未指定的角色卡、支援卡或其他卡，图像身份未知不再自动否决已经确认的全部目标。仍要求同帧六个完整卡位、两帧观测一致；只有明确识别的卡已满足全部目标时才允许通过。目标缺失或目标未知仍不计达标。

没有调整匹配模型、置信阈值、强化与绿豆判据、目标要求、票券购买规则或三分钟循环停止机制。
