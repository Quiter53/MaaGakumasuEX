# 手动停止不发送任务结果通知

用户点击停止、通过热键停止或关闭实例时，原逻辑会发送“已停止”；停止执行器未确认时还会改为“失败”发送。现在在停止请求进入队列前记录手动取消来源，发送入口统一排除该次执行，后续失败状态也不会绕过。普通取消完成分支不再调用结果推送。

自动成功、自动失败、死循环或长时间无日志触发的自动停止继续发送结果及原因。新任务开始时清除手动取消标记。通知设置页的测试按钮和本地停止提示保持原行为。

原生客户端编译通过；13 项通知分支检查覆盖成功/失败/停止、手动取消后停止失败、新任务复位和自动死循环失败。被抑制分支实际调用生产发送入口，确认在读取通知配置与网络发送前返回。测试没有发送真实微信消息。
