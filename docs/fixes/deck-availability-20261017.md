# 换出置灰牌与牌库翻页

02:19～02:20 的现场日志反复把「眠気」排为全局最优，提交未确认后从头扫描。截图中该牌置灰；说明框显示「眠気」，但橙色选中框和上方换出预览仍然是另一张牌。旧扫描只判断身份与优先级，没有判断可选状态。

稳定页面现在检查整张牌内部的遮罩，包括白色效果和费用标记，避免把自然灰色插画当成置灰。不可选牌不参与排序或详情点击；身份缓存不覆盖可选状态。提交前重新检查页面、断线和遮罩；目标变灰时重新扫描一次，提交结果不明时仍不重提。没有按名字永久屏蔽「眠気」。说明标题与上方换出预览的可靠身份冲突时，拒绝将描述绑定到仍选中的另一张牌。

现场旧拖动为 315 像素、450 毫秒，没有终点停留。改为按当前行距计算，正常三行即 12 张牌，到终点按住 350 毫秒再松开，抑制惯性。半行露出时减少距离并对齐；限一计数保留一整行重叠，维持现有跨页计数要求。移动后等待稳定再识别，动作失败交回原流程。名单、档位、限一及快速命中策略的含义不变。

验证：776 项 Python 测试、339 个子测试通过。新增检查覆盖置灰 N 让位给可选 R、恢复可选、重复牌排除、跨页重排、缓存隔离、提交前变灰、有限重试、说明冲突、三行步长、半行与坐标抖动。

用户截图去掉窗口边框后，以 720×1280 游戏内容回放原 cards.onnx 及补框逻辑，三个视区分别得到 12、12、9 张完整牌，底部「眠気」置灰，其余牌未被排除。暗色插画及自然灰色说明缩略图作为颜色判别负例；缩略图不作为可点击证据。
