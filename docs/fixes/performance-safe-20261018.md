# 同帧识别与日志图像开销优化

v2.1.0 在原有策略、识别门槛、等待时间和交易确认流程下减少重复计算。

- 出牌检测结果只在同一次截图对象内复用，新截图重新检测；选中牌核名、几何对应与连续两帧确认保持原行为。
- HIF 商店只有传入同一张已确认截图时才复用页面检查；回血、自定义等操作后的新截图重新确认。刷新日志直接使用该次交易已核实的余额。
- 饮料奖励中，完整识别的饮料行跳过补充扫描；部分识别、未知与需确认状态继续走原检查。
- 原生日志只有当前解析后的消息包含 `{image}` 时才读取图像，兼容本地文件与翻译内容；识别开始事件使用缓存截图，其余事件与通知保留原行为。

## 验证

- Python 共 955 项测试、346 个子测试通过，包含此前导出的 3600 组原生策略向量比对；原生 Focus 图像调用检查 24 项通过。
- Python 编译及原生 Release 构建通过；四种语言各 1066 条资源可加载。
- 五个 Python 文件的 93 处等待调用及数值常量保持一致；模拟完整出牌路径保留两次核名、六次截图及相同点击顺序，卡牌检测调用由七次减少为六次。
- 本机 pre 的独立 Agent 通信与正常退出检查通过，框架为 5.13.0，注册 36 个动作与 33 个识别。
- 公告在实际 Markdown.Avalonia 渲染器中检查了 900 与 580 像素宽度，包含五类正文和英文摘要折叠、展开。

这些结果属于逻辑、离线图像与组件验证；本轮尚未进行新的实机完整培育，不据此给出整体提速百分比。
