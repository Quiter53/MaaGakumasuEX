# 转换卡漏收录修复

选牌界面没有显示新转换卡的原因是公共卡库未收录，不是分类筛选问题。此前导入只接受与 `assetId` 完全同名的 PNG，并静默排除缺图条目；部分转换卡使用带角色后缀的素材名，因此被遗漏。

本次补入：再始動、衝動、競争原理、安定感、天使の微笑み、ごきげんスキップ、メイクアップ、ロマンチック、ラッシュ、ブースト。公共卡库由 446 张增至 456 张，转换卡由 21 张增至 31 张。黑白名单、出牌规则和预览手牌读取同一公共卡库。

名称及分类来自此前保存的 `gkms.idolism.org/pcard` 数据；图片来自本机 `E:\DMM\gakumas` 游戏资源，原图为 512×512，生成 96×96 选牌缩略图及现有识别器使用的 32×32 图像参考。六张角色卡当前提取到的素材为 `shro` 版本，另外四张为通用素材；没有声称覆盖尚未下载的其他角色卡图。

导入工具现支持元数据标记为角色素材的后缀文件，每张卡只生成一条选牌记录，同时保留可用的多个图像参考。任何待导入卡缺图时，在写入前报告卡名和编号，避免再次静默漏卡。原有图像参考逐项保持不变，原卡框检测 ONNX 和识别门槛未修改。

验证包括普通素材、单个角色素材、多个角色素材及缺图报错回归；全量 642 项测试和 339 个子测试通过。另核对新增卡名、转换分类、缩略图和旧图像参考前缀。未进行新增卡在真实游戏中的识别验证。

仅更新 pre 渠道及其便携包，个人规则、名单、饮料和实例配置保持不变，latest 正式版不覆盖。完全退出并重新启动 pre 助手后，在选牌窗口选择“转换卡”或搜索日文原名。
