# 按需检查持牌与限一规则

每条原生卡牌规则新增 `singleCopy` 布尔字段及“最多保留一张”开关，旧配置默认关闭。与档位提升独立，只有当前职业预设中启用的规则有效，保存规则后应用。

## 取牌与清理

- 先按当前名单、再动和有效稀有度选牌。即将获取的牌未启用限一时，直接沿用原流程。
- 奖励领取、HIF 换入、咨询购买仅在即将拿限一牌时打开当前牌组。当前候选中的限一牌共用一次检查，不使用历史点击次数或跨任务缓存。
- 已持有时优先选其他非黑名单、非已持有的限一牌。其他候选全部在黑名单或也已有一张时，允许原候选重复。咨询购买属于可选消费，已有或数量未知时跳过该商品。
- 咨询删牌及 HIF 换出先找重复的限一牌，优先级高于 N 和黑名单；确认多余副本后允许清理白名单牌，最后一张与数量未知的限一牌受到保护。每次操作重新观察，不复用上一次删除前的数量。
- 未启用限一规则的删换牌保留原快速路径。一般剧情的复制、变换入口仍为原有流程，不把它们当作已验证的咨询或 HIF 删换页。

## 识别与返回

依据 2026-10-16 用户提供的 DMM 截图，拿牌和替换牌的包包位置不同，通过同一袋子图标在底部右侧区域匹配定位，不固定点击同一坐标。牌组标题为 `所持スキルカード`，底部 `スキルカード(24)` 提供总数，`閉じる` 返回原页面。

原 `cards.onnx` 在该截图漏了一张、另一个框受右下按钮影响。新读取器保留原模型作为网格锚点，通过四条实际边缘补全卡框，用现有双区域卡图匹配器识别；不把预估网格槽位直接当卡牌。截图中 16 张可见卡全部识别名称。

回到列表顶部后，有限次翻页，按重叠行合并；重复页面不重复计数。有歧义只保留已看到的数量下界。只有统计达到页面显示的总数、且每张身份均已确认，才允许判定某张牌持有数为零。未读清的牌可经选中标记及连续两次详情核名确认。看到所有待查牌已持有时提前结束扫描。

关闭操作必须看到牌组标题和关闭按钮。返回后两帧核对原卡图、位置，点击前再核对一次。返回未确认不点击领取/下一步。若中断留在牌组页，初、NIA、HIF 入口通过专用识别关闭该页，不借用普通确认按钮。
