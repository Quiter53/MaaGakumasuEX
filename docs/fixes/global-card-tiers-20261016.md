# 培育全局使用规则档位

此前规则中的档位提升只影响战斗排序，奖励、换牌和商店仍使用真实稀有度，导致提升到 SSR 的 R 卡仍被当作可换出的普通 R。

现在统一读取当前保存的职业预设和启用的逐卡规则，在决策时计算有效稀有度：

- 奖励选牌排序及出现 SSR 后停止刷新。
- 换入卡选择、换出卡筛选，以及替换名单中 SR 优先于 SSR 的顺序。
- 商店白名单卡之间的购买排序、商店删除候选筛选。
- 常规回忆在钻石词条和绿豆数量相同后的再动、稀有度比较。

R 提至 SR 或 SSR 后，具有相同档位普通卡的保留待遇，不因原卡为 R 而自动换出或删除。显式黑名单和替换名单仍有效；白名单仍按现有方式优先获取。商店购买资格仍由白名单、价格、积分和身份核验决定，不因为升档自动买牌。

计算结果仅用于策略，不覆盖识别对象的真实 `rarity`。卡框、卡名、最终核名以及绿豆上限继续按真实卡牌数据验证。再动顺序保持不变，回合限制和曲线分数仍只作用于战斗。停用规则、切换预设、保存新档位后，后续决策重新读取有效规则。

档位提升与持牌限制独立。新增可选“最多保留一张”规则，详见 [按需持牌检查](single-copy-20261016.md)。关闭该开关时不增加查牌组操作，也不限制获得同名卡。

全局升档初次验证：653 项 Python 测试及 339 个子测试通过。限一功能集成后的验证结果以限一文档为准。未进行新的实机培育。
