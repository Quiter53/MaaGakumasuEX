# v2.0.2 本地历史代码清理

清理范围为退出正式流程的旧卡图匹配器、重复 UI 补丁、旧构建入口和失效测试断言。正式游戏策略、识别门槛、卡牌规则、饮料设置、原 ONNX、MaaFramework 5.13.0 和 PrintWindow 均保持原状。

## 删除和迁移

- 删除旧 `deck_art` 实现、64 像素图库，以及此前为它补上的兼容分支。原来针对旧匹配器的测试迁移到 `tests/test_square_identity.py`，覆盖拒识、两区域一致性、阈值、身份冲突、逐帧证据和详情确认。
- 选卡图库导入工具只更新当前共享特征；增加导入回归，验证不依赖旧图库且保留原有数据。删换牌诊断与回放直接使用正式方形卡图流程。
- 删除 `ui-patches/` 的 12 个历史文件和两个外部 UI 覆盖脚本。界面源码与测试继续使用 `native-ui/`；开发入口见 `docs/zh_cn/原生界面开发.md`。
- 删除旧 portable 构建、旧安装入口、三个禁用发布工作流及旧图库构建/分辨率试验工具。正式构建仍为 `tools/build_ex_release.py`，正式发布工具保留。
- 移除测试对已删除用户选项的要求，保留内部快速/严格扫描的行为测试，并验证奖励策略在跳过之前执行。
- 保留语言、布局、名单迁移代码、当前更新模块、移动卡牌处理、所有实际使用的识别器和历史诊断文档。

共移除 25 个历史文件。清理前已备份涉及文件，既有运行包未覆盖。

## 验证

- 45 个保留的 Agent Python 文件与原 v2.0.2 运行包逐文件 AST 完全一致。移除的是未被正式入口调用的模块，新增的旧结果兼容分支也已撤回。
- 比较清理前 1,729 个运行代码、资源和原生界面文件：除旧模块、旧图库和上述兼容分支外，全部保持一致。正式模型、共享图库、任务配置、原生界面源码没有变化。
- 相关 110 项测试、52 项子测试通过；Python 编译和 diff 空白检查通过。
- 清理包使用实际 MaaFramework 加载资源、建立独立 Agent IPC 连接并正常退出；未连接游戏。沙箱内 IPC 创建受限，沙箱外同一检查通过。
- 迁移后的诊断工具在既有删牌截图上使用原模型检出并补齐 18 个卡位，当前方形匹配器返回 18 个接受结果。该截图是回放样本，不作为独立准确率评估。
- 全量基线：46 项失败、525 项通过、1 项跳过、1 项收集错误；清理后对比：45 项失败、537 项通过、1 项跳过，收集错误消除。失败集合没有新增。随后新增的两区域匹配保护测试也通过，计入相关测试 110 项。
- 全量测试仍有既有失败，不能将本次结果描述为全套测试通过。没有通过修改正式策略来迎合旧断言。

独立本地清理包名称带 `v2.0.2-cleanup`，包内 `LOCAL_CLEANUP.md` 为本说明。版本号、原运行包及 GitHub Release 保持原状。没有进行新的游戏现场培育长跑。
