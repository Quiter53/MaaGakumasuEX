# 手牌右上角标匹配

右上角的缩略图会覆盖原始卡面。旧匹配遮罩已排除分数、左侧效果与右下费用，但没有排除这个缩略图，导致部分牌与参考卡图的相似度不足。

## 实现

- `agent/custom/hand_badge.py` 在原尺寸卡面中检查圆角白边及内侧对比，允许小幅位置、比例偏差，兼容不同缩略图颜色；连续确认时最多覆盖三层角标。
- 先运行原匹配。原本已确认的卡牌直接返回；仅未确认结果进入角标恢复分支。
- 检测到可见角标后，在截图与参考图库上使用相同遮罩；被相邻手牌遮住的区域继续沿用原遮挡处理。角标完全被下一张牌盖住时不额外遮罩。
- 恢复后的候选必须与原第一候选一致，且分数与候选差距均过门槛。剩余有效像素不足、检测未确认或两次候选不一致时维持未知。
- 原 `gates.full` 的 `0.4 / 0.09`、`gates.local` 的 `0.4 / 0.17` 保持原值。新增 `badge_full` 为 `0.4 / 0.12`、`badge_local` 为 `0.4 / 0.20`；角标分支要求更大的候选差距。分数不是正确概率。
- 缓存键包含原尺寸角标区域，避免边框变化后使用旧恢复结果。计算有固定上限，不引入点击、等待或跨帧流程状态。

## 验证

基线为 `v2.1.3`，普通出牌检测仍使用原 `cards.onnx`。

| 样本 | 原匹配正确 | 新匹配正确 | 新增错认 |
| --- | ---: | ---: | ---: |
| 历史手工牌框，34 次卡牌身份 | 33 | 34 | 0 |
| 视频一静止手牌，64 次身份 | 60 | 63 | 0 |
| 独立视频二静止手牌，29 次身份 | 27 | 27 | 0 |
| 合成单层角标，3000 次身份 | 2816 | 2930 | 0 |
| 合成单至三层角标，1500 次身份 | 1333 | 1403 | 0 |

两组合成实验各有相同数量的无角标对照，结果逐项保持一致。另有 900 个无信息负样本，原匹配有 20 次错误接受，新分支没有增加错误接受；不能把整套实验描述成零误识别。

视频共抽取 447 帧，逐图目视核对 59 帧、136 次卡牌身份，并按原录像分为开发与测试。标注由 Codex 根据标题、卡面与相邻帧核对，未经过独立人工审计。它们评估给定、目视检查过的检测框中的身份，不能当作整手检测召回率。近重复检查标出一帧；去重后静止样本为 92 次，原匹配正确 86 次，新匹配正确 89 次，均无错认。

原图、标注、来源、裁剪及哈希见 MaaGakumasuEX-Lab 的 `datasets/video-eval-20261025`。第二段为长屏手机视频，先裁出手牌所在视口，再等比例缩放；不能用来声称完整长屏流程适配。

在去重后 92 次静止身份上交替顺序串行测试三轮，单卡身份匹配平均耗时从 39.6ms 到 41.2ms，中位数均约 40.3ms；此测量不含截图、检测和游戏动画，不能推算整局耗时。

1211 项 Python 测试与 1307 项子测试通过。尚未进行新一轮实机完整培育。

## 后续模型判断

本轮没有训练或替换神经网络。角标恢复已带来可复现的新增正确识别，普通路径保持原判断。剩余三个视频静止难例分别涉及重度遮挡和置灰，保留在测试集中。现有录像来源和难例数量不足以证明新特征模型更好；后续候选需在原录像隔离的测试集上同时比较错认、拒识与耗时。
