## 修正

- 回血满血报价按 2 体力/10P 的档位校验；最后一档显示恢复量可以被体力上限截断。预算也按完整档位计算，避免只差 1 点满血却提前停止。余额不足一档时不打开回血框。
- 保留恢复量双处文字、体力、前后余额检查，连续确认报价后才付款，付款后继续检查体力与余额，不放宽 OCR 分数或取消防重复付款保护。
- 卡牌回忆单独记录是否满足目标，停止再生成不再使用候选比较分数。非目标牌或强化/绿豆不足，即使有钻石也继续尝试。
- 已收集普通目标不会阻止继续找其他目标；已满足条件的目标钻石回忆仍按原策略保留。普通培育比较顺序、卡组模式、票开关、票不足与未知识别保护保持原行为。
