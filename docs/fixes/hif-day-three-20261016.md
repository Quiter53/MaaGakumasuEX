# HIF 第三周行动

HIF 本战设置在“上课属性”下新增“第三周选项”，依次为外出、支给、休息，默认支给以延续原流程。选择外出后显示“外出选项”，默认第一选项，可改为第二、第三选项。沿用原生任务下拉框和子选项机制，补齐四种界面语言；汉化任务使用同一套培育难度配置，无须复制选项定义。

## 执行方式

- `ProduceHIFStrategy.attach.day_three_activity` 保存行动，`outing_option` 保存外出选项；不与 `lesson_option` 共用。
- 识别下部日程入口的完整文字。截图中的第三日外出/支给组合用于识别该活动页，不把顶部“距本战剩余 3 日”错当作第三周。外出或休息要求同时识别外出和支给；默认支给仍支持原有单独的差し入れ入口。
- 两次新截图确认入口位置后单击。目标暂时缺失时交回入口重识别，不自动改选支给。休息复用既有确认按钮，识别到次数为零时不点。
- 外出页由标题独立识别，复用现有四种三选项模板，收集全部匹配行后按纵向顺序选择。允许三行使用同一种模板；连续画面确认后单击，后续确认继续重新识别，不盲目双击。
- HIF 通用选项兜底也检查当前页面类型，交给外出或上课处理；标题暂时缺失时重识别，不采用普通培育的随机属性策略。初、NIA 继续原策略。
- 外出识别放在战斗、奖励、商店处理之后，避免每张牌额外执行外出标题 OCR。中断恢复加入外出页。短时漏识别不直接结束任务或关闭游戏，既有全局死循环检测仍有效。
