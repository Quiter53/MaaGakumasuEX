# 限一牌同名交换

此前 HIF 换入复用普通奖励规则，检查到已经持有时会改选其他非黑名单牌；换出又保护限一牌的最后一张，未支持“自己换自己”。

现在只有 HIF 换牌传入交换模式。当前牌组确认目标至少持有一张、并确认返回原选择页后，可以继续选该目标，同时将本次换出限定为同名旧牌。普通奖励与咨询购买保持原行为，持有数量未知不能授权同名交换。

换出约束保存在当前任务资源节点的 attach 中，不写个人配置，不保存旧坐标。每次选择新目标先清除前次约束；确认提交推进后再清除。来源页及最终提交都重新核对右上换入卡图；不匹配或读不清时不点击。扫描仅接受已确认身份且可选的同名牌，可以跨页寻找，优先级高于普通删换规则，允许换出被白名单、提升档位或最后一张保护的同名牌。没有可选同名牌时保留现场，不能用其他牌换入而增加副本。咨询删牌不获得这项权限。

789 项 Python 测试及 339 个子测试通过，包括交换/普通奖励分流、未知持有量、约束保存清除、跨页同名寻找、置灰排除、最后一张白名单提升牌、目标变更拒绝提交。未进行新的实机换牌验证。版本仍为 2.0.3，仅更新 pre。
