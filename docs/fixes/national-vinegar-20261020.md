# 国民、初星黑醋与 SSR 出牌降档

## 已确认策略

- 国民规则增加单个 `comboTarget`，可清除，普通/强化共用，跟随当前预设和规则启用状态。
- SSR 的 `tier` 可设 R/SR，战斗预览和真实出牌采用降档；培育选牌、买牌、删换牌、回忆使用原稀有度。原 R/SR 升档行为保留。
- 黑醋 ID `767772` 只采用 `rule_combo`，旧时机读取时转换，目标饮料开关不变。无配合配置时不使用，末回合也不强制使用。
- 原排序先选牌；若该牌是国民或配合牌，再检查完整当前手牌。只缺另一张时触发黑醋，两张都有、不确定另一张是否在手里、或没有黑醋时继续原出牌流程。
- 喝黑醋后选择指定牌，找不到则选择能识别的最高规则优先级牌。回到手牌后重新排序，不设置锁定牌，不提高国民或目标牌优先级，不强制连招，不等待凑齐组合。
- 用户确认：国民成功打出后的下一张牌不触发黑醋；只选中或点击未提交成功不清除该状态，其他饮料时机不变。
- 回合或相对排序冲突由界面提示，实际遵守用户规则。取回的牌当前不能打，也不强行使用。

## 识别与有限重试

- 原模型漏检用户截图左侧「シュプレヒコール」。以检测到的同排卡位为锚，要求四条实际边框成立才补回漏检格；空格不产生候选，不替换 ONNX 或降低原识别阈值。
- 点选后要求两帧完整卡名一致、四角选中标记对应当前卡位，确认「移动」按钮启用才提交。页面变化即停止旧坐标操作。
- 取牌页最多扫描 8 页，总处理上限 65 秒；找回备选时重新定位，不复用上页坐标。移动按钮未接收时最多提交 3 次，每次重新核对当前标题、卡位与按钮。
- 单次出牌准备只启动一次黑醋取牌，失败不连续喝下一瓶。没有可确认候选、无法确认页面或转场失败时给出明确错误并保留现场。
- 取牌时断线交回原全局恢复流程；手动停止正常退出，不记为喝药失败。设置界面的冲突提示随档位、回合和曲线修改刷新。
- 使用真实截图离线验证了漏检卡位恢复、未选择/已选择标题、四角标记、按钮启用与移动点击。最后一张用户截图仍处于动画、未显示 SKIP；没有把它冒充已稳定返回出牌页。
