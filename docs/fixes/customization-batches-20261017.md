# 自定义分批与特别指导

HIF 轮间商店的两个名额按实体卡计算。同一张牌进入菜单后，按设置的选项和最终次数补足进度，再换下一张牌；不会将 R 卡的三次自定义误计为三个商店名额。

轮间商店流程为回血、本批自定义、当前目标饮料、检查剩余预算、刷新、下一批自定义。只有已确认尚有目标未完成，而且买药后的余额足够支付刷新及下一次自定义时，才为了自定义刷新。满栏都是目标饮料时保留饮料，仍可为待完成自定义刷新。全部完成后不重复扫描目标，继续原饮料与离店流程。

普通特别指导使用相同的进度与扣款识别，但使用独立状态：每节点最多两张卡，消耗 P 点，没有刷新和购买饮料。节点进入时重置本节点状态；不与轮间商店共用未确认交易。共用菜单恢复时根据已确认的事件状态路由；列表根据底部结束/返回控件区分。不开启自动自定义时，保留原特别指导模板入口和退出行为。

列表预览出现全部选项“カスタマイズ上限”时直接跳过该副本，不点击灰色入口。半成品只补足缺少次数。第一张/第二张中途积分不足时保留已完成操作，停止本店自定义，继续原商店后续流程；普通指导则退出节点。未知价格、灰色入口原因不明、扣款或名额变化不明时，不猜测完成或重复提交。

原生目标窗口支持拖动排序，保留上移、下移按钮。顺序决定执行优先级，移动不改变选项次数。HIF 本战第三周选项后新增“普通商店删牌”，默认关闭；普通删牌事件及其他剧本商店不受这个开关影响。
