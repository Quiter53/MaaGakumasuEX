# 自定义再动

原生出牌规则的“排序档位”下、“最多保留一张”上方新增“自定义再动”开关，默认关闭。每张牌、每个职业预设分别保存。用于用户已经在游戏中自定义为再动的牌，助手按保存的设置进行策略判断。

开启后立即更新卡片再动标记及手牌顺序预览，点击“保存规则”后应用到实际任务：

- 出牌按再动档比较，仍遵守使用回合限制，再比较有效稀有度和同档曲线。
- 奖励选牌/HIF 换入及咨询购买排序按再动牌比较，奖励刷新停止条件也把它作为再动牌。
- 常规回忆仍先比较钻石词条、绿豆数，再使用包含自定义再动的优先级。

关闭开关、停用整条规则或切换到没有此设置的预设后恢复原判断。自然再动不会被关闭开关降为非再动。同名强化版沿用同一规则。新增可选布尔字段 `customExtraAction`，旧文件缺失时默认为 false；真实识别结果、图标分数、出牌后复核和原卡库不被改写。

验证：687 项 Python 测试及 339 个子测试通过；533 项原生检查通过；3600 组原生/Python 策略结果一致，新增再动开关开关态及规则停用比较。界面保存/重载、预览排序、四语言及浅深主题渲染检查通过。未进行新的实机完整培育。

版本仍为 2.0.3，开发和安装仅在 pre，个人配置与 Latest 保持不变。
