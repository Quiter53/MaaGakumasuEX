本版为预发布测试版，正式版与 GitHub Latest 为 v2.1.3。默认更新渠道仍为「稳定版」；需要测试版时，在「设置 → 版本更新 → 更新渠道」选择「测试版」。

本机 Windows 验证：1242 项 Python 测试、1307 项子测试及 12 项 Lab 测试通过，原生策略向量检查未跳过。20 个原失败裁剪逐字节一致，配对回放由修复前接受 20 次变为修复后 0 次；整屏重建中 18 帧像素哈希一致，另 2 帧哈希不一致，不能视为全部整屏逐字节复现通过。34 次历史身份及 135 次去重录像身份的原有结果字段均无变化。

此前 Linux 归档的两组合成负样本为 20/900 → 0/900，额外种子为 2/150 → 0/150；正常合成与已有截图统计见 [Lab 复现记录](https://github.com/Quiter53/MaaGakumasuEX-Lab/tree/main/datasets/negative-acceptance-20261030)。合成结果不代表实机准确率，尚未新增云端实机完整培育验证。

保留原 cards.onnx、MaaFramework 5.13.0、DMM PrintWindow、更新渠道设置与个人策略配置。请下载完整 Windows x64 便携包；`PORTABLE_BUILD.json` 记录构建提交与渠道。
