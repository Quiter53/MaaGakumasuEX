# MaaGakumasu EX v2.0.1

修复已进入允许使用回合的卡牌，在选中后因追加回合 `+N` 短暂漏读而反复暂缓的问题。

- 追加回合的常规 OCR 置信度不足时，定位白色标签并裁出内部字符，使用独立文字识别复核。识别门槛仍为 0.90，总回合数仍需两次一致读数。
- 已选中牌的回合数暂时未知时，在同一张选中牌上最多补充三帧观察，恢复后继续出牌；选中牌改变或断线时交回恢复流程。未知读数不计入该牌的规则暂缓次数，不沿用旧回合数强行出牌。
- 移除普通日志中的“时机保留”“大刀保留”和疑似受限牌播报；诊断细节保留在 DEBUG 文件日志。
- 卡牌规则、职业预设、优先级、饮料设置和原识别门槛保持原样。出牌前指定饮料仍按配置执行。
- README 补充 EX 使用、规则排序、配置迁移与本地构建说明。

## 验证

相关回归 78 项，其中 77 项通过、1 项因缺少本地跨语言向量文件跳过；包含 12 项新回归。另行执行旧饮料测试有 4 项测试替身错误，在未修改的 v2.0.0 运行代码上可复现相同错误。

真实 MaaFramework 5.13.0 在历史截图上验证了新增裁剪识别路径，`+1` 的独立识别分数为 0.984056。为触发该路径，测试将前置常规 OCR 的结果替换为故障日志中的低分读数；后续裁剪与 OCR 使用真实截图和引擎。用户本次压缩包只有日志，没有故障帧，尚未进行本次场景的实机长跑。

## 使用

下载完整 Windows x64 ZIP，解压后运行 `MaaGakumasu.exe`。从旧版迁移时先退出助手，保留自己的 `config/` 和 `appsettings.json`；公共卡牌库 `config/card_library.json` 使用新版文件。原有卡牌与饮料规则无需修改。
