# v1.5.2

## 更新内容

- HIF 上课完整处理属性与回答选项；课程按第一、第二、第三属性的 SP 优先，再考虑三个属性的普通课程。课程排序以偶像偏好为准，SP 优先用于获取星耀值。
- 换出及商店删牌共用 N → 黑名单 → R → 替换名单优先级，跨页保留最优候选；替换名单内 SR 优先于 SSR。详情精确核对数据库身份后提交，删除同时核实确认弹窗与实际扣款。
- 换出页按卡框空间位置对应比较稳定帧，兼容同排 1 像素抖动和检测顺序变化；稳定后识别牌面，核实最高优先级 N 卡即可停止翻页。
- 普通及 HIF 轮间商店只购买六种目标中的最低价可负担饮料，空位允许购买同种；满栏存在非目标饮料且确认可购买目标时腾位，满栏全部为目标则保留。没有可负担目标时保持持有饮料，普通商店保留积分，轮间商店按预算刷新寻找目标。
- 奖励饮料逐格识别目标与持有栏，满栏补目标时核实非目标饮料并腾位；兼容已勾选“不领取”的页面。丢弃前复核日文名称、确认内容及栏位减少。
- 商店入口、日程入口、购买后重进与退出分离，等待商品稳定后扫描；页面已离店交回培育流程。常规日志显示决策和结果，逐卡探测写入调试日志。
- HIF 开始、两轮试镜及失败收尾采用专用分流；结算出口统一执行培育次数检查，达到设置次数后停止下一局准备。
- 卡牌页面提供好调、集中、干劲、好印象、强气、全力六套独立预设，以及黑名单、白名单、替换名单三列，编辑后立即保存。本包保留当前名单预设。
