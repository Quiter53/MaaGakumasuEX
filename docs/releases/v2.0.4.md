# MaaGakumasu EX v2.0.4

Windows x64 正式版，修复 v2.0.3 回忆结算后卡在奖励弹窗的问题。

## 修复内容

- 回忆提交“下一步”后，确认已离开回忆页面并出现圆形关闭按钮时，交回正常结算流程关闭贴纸、物品奖励弹窗，避免一直等待直到循环检测停止任务。
- 再生成并确认候选后，记录已完成选择，直接继续结算，不再寻找已消失的再生成入口。
- 修正再生成入口未确认时的提示，不再误报“本轮未使用再生成票”。

保留现有卡牌名单、出牌规则、饮料策略、用票限额、识别模型和识别门槛。MaaFramework 仍为 5.13.0，DMM 仍使用 PrintWindow。

## 下载与升级

下载 `MaaGakumasuEX-v2.0.4-win-x64-portable.zip`，退出助手后解压到新目录，运行 `MaaGakumasu.exe`。已有用户可迁移 `config/` 与 `appsettings.json` 中的个人设置，保留新包的 `config/card_library.json` 和 `config/pip_config.json`。发行包默认使用稳定更新渠道，不包含个人连接、通知凭据、日志或回忆进度。

## 验证范围

- 全量 933 项测试、346 个子测试通过，无跳过；包含使用原生界面此前导出的 3600 组策略向量，与当前 Python 后端对照的一致性检查。
- 上传截图中，原圆形关闭按钮模板经 MaaFramework 5.13.0 离线匹配得分 0.921918，高于原门槛 0.8。
- 便携包资源加载、独立 Agent 通信与正常退出，以及 ZIP CRC 和逐文件 SHA-256 校验。
- 本次尚未进行新的实机完整培育验证。
