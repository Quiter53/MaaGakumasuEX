# v2.1.1

## 新增 | New

- 培育与偶像之路新增「出牌后等待时间」，默认 1.5 秒，可设置为 0～5 秒，支持两位小数；设为 0 时取消额外等待，动画结束、手牌稳定与出牌提交确认继续按原流程执行。

## 改进 | Improved

- 调整「出牌后等待时间」设置布局，名称与输入框在同一行显示，统一与相邻选项的间距；说明移至问号提示，补齐简中、繁中、英文与日文文案。
- 饮料上限选择页的简洁日志显示图标未核实的具体原因与列表位置，便于定位反复识别的问题。

## 修复 | Fix

- 修复饮料上限选择页中，杯形饮料图标轻微偏移时匹配不稳定的问题；常规匹配未通过时细化图标对齐位置，保留原识别阈值、候选分差与连续截图复核。

## 文档 | Docs

- 补充出牌等待时间的设置说明与识别耗时分析，明确额外等待的生效位置及日志耗时的统计范围。
