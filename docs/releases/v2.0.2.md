# MaaGakumasu EX v2.0.2

- 新增十张卡的日文名称、本机游戏原图及卡面识别特征。卡牌名单、出牌规则、饮料触发选牌与回忆选牌共用更新后的 446 张卡库。
- 原生规则页的手牌与移除按钮合为一体；统一操作按钮的可见高度，调整字号、行距、标签宽度和卡图比例。选卡项按内容展开，避免多行文字截断。
- 设置页新增「输出详细日志」，默认关闭，可随时切换。普通日志隐藏识别参数与异常堆栈；完整诊断仍保存在文件中。「调试诊断」独立控制异常截图，删除其下方说明小字。
- 移除培育任务内重复的「卡片选择优先级」选项。培育说明简化为提醒配置卡牌名单、饮料与出牌优先级。
- 补齐简中、繁中、英文和日文任务及 EX 页面翻译，包含筛选项、计数、状态和曲线标签。日文卡名、保存的预设标识与规则数据保持不变。
- 新便携包默认采用左侧任务与说明、中间设置、右侧完整日志的布局，默认关闭实时视图。手动启用时，实时视图与日志上下排列。

## 新卡

見惚れる横顔、応えたい気持ち、受け止める光、無自覚チャーム、なりきりデビル、出発進行ですわ～♪、スイートトラップ♡、わたしは、風！、悪戯ハートジャック、うたたねレポート。

名称与分类核对自 [Hatsuboshi Library](https://gkms.idolism.org/pcard)，图片取自本机已下载的 DMM 游戏资源。更新的是名称目录和卡面匹配特征库，原 `cards.onnx` 卡牌框检测模型、MaaFramework 5.13.0、DMM PrintWindow 和识别门槛保持不变。

## 验证

原生规则页通过 503 项检查，覆盖四种语言、保存、节点拖动、预览与选卡按钮；卡牌名单与饮料页原生测试通过。规则回归包含 3,600 组 C# / Python 计算一致性校验。十张新卡原图缩放后的匹配自检均命中正确名称，分数 0.972–0.986；旧特征数组逐项保持一致。这些属于离线验证，未进行新卡实机长跑。

旧 `test_deck_art` 中一项对身份确认的断言仍失败；在未修改的 v2.0.1 运行代码上可复现，未将其计为本次测试通过。

## 使用

下载完整 Windows x64 ZIP，解压后运行 `MaaGakumasu.exe`。升级前退出助手，迁移原有 `config/` 与 `appsettings.json` 时保留新版 `config/card_library.json`，以免用旧卡库覆盖新增卡。个人规则、名单和饮料设置无需重设。新用户使用新版默认布局；已有用户继续使用自己的布局设置。
