# v2.3.0 测试版

## 新增

- 出牌状态条件。可组合剩余回合、全力值和全力／強気／温存状态，设置使用限制或临时优先级。
- 通用连携。为起始牌指定后续候选，按顺序寻找可用牌，可设置等待回合、首次连携前保留或仅连携使用。
- 保留选牌名单。全力、强气职业及热绿茶的选牌页可按名单选牌，支持名单顺序和先遇到先选。
- 职业配置分享。导出当前职业规则，导入后可检查和修改，保存后生效。
- 手牌模拟增加全力值和状态设置，便于检查条件与排序。

## 测试说明

新增规则默认关闭。状态读取不确定时，条件优先级使用原曲线，受限牌等待条件确认。连携在确认出牌成功后推进，等待达到上限后解除。

本版通过 Lab、原生界面及便携包检查。实机全力状态识别、双选保留与完整培育尚未验证。
