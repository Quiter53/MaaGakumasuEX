# v2.3.1 测试版

## 新增

- 出牌状态条件，可组合剩余回合、全力值和全力／強気／温存状态。
- 通用连携，可设置后续候选、等待回合、首次连携前保留及仅连携使用。
- 保留选牌名单，用于全力、强气职业和热绿茶的选牌页。
- 职业配置分享，导入后先进入草稿，保存后生效。
- 手牌模拟支持全力值与指针状态。

## 修复

- 补齐 Windows CI 的 Python 运行依赖，让原生客户端与 Python 的策略对照测试完整执行。

## 测试说明

新增规则默认关闭。状态读取不确定时，条件优先级使用原曲线，受限牌等待条件确认。连携在确认出牌成功后推进，等待达到上限后解除。

Lab 回归通过 1480 项测试、1325 个子测试，原生界面通过 806 项检查，跨语言对照通过 3640 组策略结果。隔离 CI 依赖环境通过 108 项检查。实机全力状态识别、双选保留与完整培育尚未验证。

Release 构建保留 9 条历史编译警告，涉及未等待的异步调用、弃用接口和未使用成员。本轮新增产品代码未增加编译警告。
