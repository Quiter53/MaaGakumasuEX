# MaaGakumasu EX v2.0.3

Windows x64 预览版，汇总 v2.0.2 之后的独立修复包。应用与资源版本为 `v2.0.3`，Python 项目版本为 `2.0.3`。预发布状态通过 GitHub Release 的 Pre-release 标记管理，不写入版本号。

## 修改内容

- **限一牌同名交换**：HIF 换牌检查到目标已经持有后，可以用同名可选旧牌换入，数量不增加。允许换出最后一张或白名单中的同名牌；目标核对失败、旧牌置灰时不替换其他牌。普通奖励与商店购买的限一策略不变。详见 `docs/fixes/self-exchange-20261017.md`。
- **换牌与翻页**：置灰牌退出换出候选，提交前变灰则重选；核对说明标题与实际换出预览。牌库按行距移动，正常每次三行、12 张，终点停留后松开；半行和限一计数场景保留必要重叠。详见 `docs/fixes/deck-availability-20261017.md`。
- **控制器配置入口**：将“控制器预设配置”从任务列表移至“设置 → 连接设置”，保留已有 DMM 点击延迟、输入校验和自动参数应用；它不是独立任务。详见 `docs/fixes/controller-settings-20261017.md`。
- **HIF 自动自定义**：新增默认关闭的开关及原生目标编辑器，逐卡设置左到右选项的最终次数和目标顺序。轮间商店在回血后、买饮料前执行，识别已有进度、每项上限、费用和余额；已确认还有目标且刷新后买得起时继续刷新。扣款未确认不重复提交，中断页面有专用恢复。详见 `docs/fixes/auto-customize-20261017.md`。
- **HIF 差し入れ领取页**：补齐中断恢复入口，联合识别页面标题和领取按钮后继续培育，避免该页启动任务时 20 秒超时。日程选择策略不变。详见 `docs/fixes/hif-supply-receipt-20261017.md`。
- **源码组织**：培育逻辑按事件、选项、战斗、奖励、商店、回忆等职责归档，第三周日程辅助合入 HIF 共用模块；保持当前策略、识别参数和操作时序。详见 `docs/development/source-layout.md`。
- **HIF 第三周行动**：在上课属性下增加外出、支给、休息，默认支给；选择外出时展开第一至第三选项。外出按所选顺序执行，与上课选项独立。详见 `docs/fixes/hif-day-three-20261016.md`。
- **自定义再动**：排序档位下新增默认关闭的开关，用于游戏内自定义后获得再动的卡。保存后按再动牌参与出牌、奖励/HIF 换入、咨询购买排序及常规回忆比较；预览与卡片标记同步，四语言可用。详见 `docs/fixes/custom-extra-action-20261016.md`。

- **按需限一张**：逐卡规则新增默认关闭的“最多保留一张”。准备拿该牌时检查当前牌组，已持有则改选非黑名单牌；其他候选均被排除时允许重复。咨询删除、HIF 换出优先清理重复副本，保护最后一张。包包按图标定位，关闭后核对原画面；详情页中断有专用恢复。详见 `docs/fixes/single-copy-20261016.md`。

- **培育全局档位**：规则中的稀有度提升同步应用于奖励、换牌、商店和常规回忆比较；R 提至 SR／SSR 后不再作为普通 R 自动换出或删除。真实识别稀有度、再动、名单及购买资格保持原有含义。提升本身不限制同名牌数量。详见 `docs/fixes/global-card-tiers-20261016.md`。
- **转换卡补录**：补齐此前漏导入的 10 张转换卡，卡库共 456 张，其中转换卡 31 张。同步选牌缩略图、卡名目录和图像参考库；导入工具支持角色后缀素材，缺图会明确报错。详见 `docs/fixes/conversion-cards-20261016.md`。
- **日志循环检测与结果通知**：连续 5 分钟无任务日志，或固定日志循环持续 3 分钟且至少重复 30 条时停止任务，保留游戏现场。详细日志开关不影响检测，手动等待暂停计时。外部通知包含结果、任务、原因和耗时；修复出错后继续误报成功，以及微信服务拒绝仍被当作发送成功的问题。详见 `docs/fixes/task-log-watchdog-20261016.md`。

- **剧情跳过确认**：关闭关注租借时，取消操作仅作用于已识别的关注界面。结算入口优先处理剧情确认，点击前重新截图核对标题、正文及按钮。缺按钮时等待重识别，不新增结束培育或关闭游戏的行为。
- **常规培育再生成回忆**：新增默认关闭的开关，开启后每轮最多使用一张再生成票。先比较钻石词条是否存在，再比较获得卡的绿豆数量，最后按再动、稀有度选择；同分保留原回忆。票不足或出现钻石购买提示时继续原结算，中断恢复不重复用票。
- **商店访问状态**：离店后结束旧访问，下一店重新扫描；同店重入、未知画面和断线恢复仍保留防重复消费保护。
- **歌曲与任务配置**：歌曲识别兼容 `℃`、`°C` 等等价字符；恢复官服与汉化任务各 13 个自定义歌曲入口及四种界面语言说明。
- **维护清理**：移除已停用的旧匹配器及依赖、重复原生 UI 副本、过时构建入口；修正与现有行为不一致的测试，保留正式入口与恢复行为的回归覆盖。

保留原生界面、出牌规则、名单、饮料策略和日志设置。原 `cards.onnx`、MaaFramework 5.13.0、DMM PrintWindow 保持不变。

## 使用与配置

解压 `MaaGakumasuEX-v2.0.3-win-x64-portable.zip` 到新目录，运行 `MaaGakumasu.exe`。

迁移旧目录的 `config/` 和 `appsettings.json` 可保留实例、设备、名单、规则与饮料设置；请保留新版的 `config/card_library.json`、`config/pip_config.json`。发布 ZIP 使用默认配置，不包含个人实例、凭据、日志或回忆收集进度。本机整理时，可以在完成 ZIP 校验后单独迁移个人配置到解压目录。

首次使用默认关闭详细日志、调试截图及实时视图；已有用户沿用自己的配置。常规培育“再生成回忆”默认为关闭，需要用票时手动开启。

- 789 项测试、339 个子测试通过，零失败、零跳过；原生界面沿用前次 570 项检查及 3600 组策略向量验证。控制器设置覆盖旧值恢复、保存、参数生成、切换与运行锁定。自定义功能包含用户截图的实际 OCR 回放、选中框 ±3 像素扰动、牌库框抖动去重和交易防重提检查。历史剧情循环日志回放在 187.4 秒检出。
- 实际 MaaFramework 5.13.0 的 16 组离线路由验证覆盖初、NIA、HIF、结算入口，以及两种关注设置和按钮暂时缺失。
- 剧情修复另通过原模板合成画面的真实 OCR/模板匹配与负例检查；现场日志只有 OCR 结果，没有原始截图，不把合成画面或模拟路由当成现场实机验证。
- Python 编译、原生资源加载、独立 Agent 进程通信与正常退出、ZIP CRC 及逐文件 SHA-256 校验均纳入打包检查。
- 仍未进行新的实机完整培育，作为预览版交付。未启用限一规则时，快速换牌保持当前页合规牌优先的行为；启用后先扫描重复副本。

详细记录见源码 `docs/fixes/` 中的培育修复、常规回忆再生成和剧情确认说明。
