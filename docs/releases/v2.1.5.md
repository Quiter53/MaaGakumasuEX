# v2.1.5

## 改进 | Improved

- 出牌阶段复用同一帧已有的卡牌检测结果，减少规则选牌与喝药前检查的重复推理；切换画面后仍重新识别。
- 手牌身份匹配缓存固定卡图库的区域统计量，减少重复计算；保持原有相似度、分差门槛与匹配结果。
- 卡牌规则选牌窗口复用卡牌控件，选择时仅更新选中状态；黑白名单筛选按差量更新列表，减少输入与切换时的控件重建。
- 更新检查复用版本列表中的下载资产信息，末页不足一页时结束查询，减少重复网络请求。

## 修复 | Fix

- 修复日程与工作页体力读取仍使用包含爱心的旧 OCR 区域的问题；统一数值解析，按页面布局限定图标右侧区域，不再将未知体力当作满体力或 0 参与选择。
- 修复日程 P 点数读取与商店布局混用、解析失败被当作 0 的问题；未读清时交回场景识别，并在调试日志中记录区域与失败原因。
- 修复卡牌名单保存期间读取失败会临时关闭名单的问题；文件未变化时复用有效结果，文件更新后重新加载，暂时损坏时保留上次有效设置。
- 修复更新资产选择可能选中校验文件或未上传完成文件的问题。
- 修复保存截图同步等待文件选择窗口可能阻塞界面的问题；异步选择保存位置，并保留发起保存时的截图。

## 文档 | Docs

- 更新体力与 P 点数的置信度入口说明，补充根因、离线对照结果与验证范围。

本次为测试版。原 cards.onnx、MaaFramework 5.13.0、DMM PrintWindow、出牌优先级及用户等待时间保持原设置；未完成新增实机完整培育验证，日程与 NIA 工作页仍需云端长流程确认。

固定 20 帧、65 个牌框的离线身份匹配对照逐字段一致；该步骤耗时中位数约下降 17%，不代表整局提速。详细验证见 [v2.1.5 根因与验证记录](v2.1.5-validation.md)。
